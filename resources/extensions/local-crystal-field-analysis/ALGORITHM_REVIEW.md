# 算法审核与数学约定

## 2.1.0 双模式补充（2026-10-20）

PDOS 采用逐原子、逐 lm、逐自旋电荷谱。对相邻样本 `(a,u),(b,v)` 的线性段，零阶积分为 `(b−a)(u+v)/2`，一阶积分为 `(b−a)[(2a+b)u+(a+2b)v]/6`；先在用户区间端点插值，再逐段求和。不能用梯形积分 E·DOS 的近似代替这里线性 DOS 的精确一阶矩。Python 与页面使用相同物理定义、独立解析实现，已知线性谱、截断端点及实际导出逐项对照。

负谱权重不裁零，非正总权重没有重心。线性插值采用凸组合，避免非负端点产生浮点消减造成的假负值提示。默认完整范围不等于完整谱空间。分组重心定义为各条参考能量的算术平均，不暗中改成总 DOS 强度加权重心。

本征能级、指定基底 Hₘₘ 与 PDOS 重心分别标识；哈密顿量保留复数与非对角项。对角元可随坐标基底变化；同一固定子空间内的酉变换保持其完整本征谱，但跨子空间混合和模型改变不具备该保证。SOC 数据不伪装成独立无 SOC 五轨道谱。

PDOS 本轮用明确标记的合成 DOS 文件验收；真实 Cr2FeS4_pri 使用本机已冻结的 25366 矩阵回放。没有因本轮开发重新读取研究服务器或重跑计算。来源程序结束、数值诊断与物理验证继续分别记录。

审核日期：2026-10-14。新版 2.0.0；旧版 0.1.0 保留作历史复现。

## 合理的核心与必要修正

旧版从 R=0 取局域 d 块、用归一化无迹对称二阶张量表示实 d 球谐、Kabsch 拟合配位方向，再按迹计算立方子空间重心，数学上成立。但需要明确条件：最终 Wannier 基底必须对应所声明的轨道、相位和方向，且选定原子子空间具有可接受的局域性。同一原子块各 WF 必须采用相同原胞平移；若各轨道独立平移，物理同原子矩阵可能来自非零 R，不能把原 R=0 子块直接当作对齐后的 onsite。初始投影不保证这些条件。WF 跨原子/壳层酉混合会改变局域投影块；原子块和晶场分组不是任意 Wannier gauge 下的不变量。

本轮修正固定 O 配体和 Cr/Fe/WF 索引、仅支持 d 壳、取实部、输入解析不完整/截断可能挂起等限制。新解析流式核对所有 R 块、索引覆盖/重复、有限数和记录数，保留 R=0 原文及行号。要求原位 R 简并度为 1；不对未经确认的异常权重偷偷重标度。这里不做 H(k) 插值，因而不套用有限网格填充、wsvec 修正或固定整数占据推断。

## 公式和可复现过程

1. `H₀ = H(R=0)`，单位 eV。Wannier90 `_hr.dat` 第 2/3 行是 WF/R 数，简并度块后每行是 R、m、n、ReH、ImH；m/n 从 1 起。不是只读对角元。
2. 检查 `max|H₀−H₀†| ≤ 10⁻⁵ eV`。容差内取 `(H₀+H₀†)/2`，保留最大修正；这不等于丢弃虚部。
3. 按明确 WF 索引提取完整原子块和 s/p/d 子壳块。`H_A = P_A H₀ P_A` 的非零子空间谱只属于该限制块。完整原子块还含不同 l/径向壳间耦合。
4. `H U = U diag(ε)`，ε 升序；权重为 `|Uᵢₙ|²`，每列和为 1。重心 `Tr(H)/dim`，范围 `max ε−min ε`，RMS `sqrt(mean[(ε−ε̄)²])`。常数能量平移改变重心，保持劈裂与减重心谱；一般跨壳/原子 gauge 变化不具有此不变性。
5. Q 的列是局域 x/y/z 轴。d 用 Frobenius 正交归一的无迹二阶张量 Bᵢ：`Rᵢⱼ=Tr[(Q Bᵢ Qᵀ) Bⱼ]`；p 在 z/x/y 顺序中采用对应向量表示，s 为 1。`R Rᵀ=I`。
6. 原始投影轴到全局候选：`H_global = R_projectionᵀ H_raw R_projection`。全局到配位架候选：`H_local = R_local H_global R_localᵀ`。spinor 使用 `R⊗I₂`，不丢弃自旋混合；各旋转矩阵和代入矩阵保存在 JSON。本机和服务器的 SVD 在高对称配位时可能选取不同的立方等价架；跨环境验收比较原始/全局矩阵、完整谱、子空间谱、重心差和混合范数，不要求局域矩阵逐分量一致。冻结 Q/R 用于复现具体分量。
7. 显式配体/配位数，在 pymatgen 周期晶格度量中取最近 cn 个邻居及下一个距离，再以单位方向拟合理想六配位/四配位参考。真实旋转 detQ=+1；方向 RMSD 无量纲，键长 Å。近等距邻居、严重畸变或多面体方向选择可能导致不唯一；排序编号不等于配位化学证明。
8. 完整非 spinor d 壳的条件性立方分组：`e/eg={dz2,dx2−y2}`，`t2/t2g={dxz,dyz,dxy}`。八面体 `Δoct=Tr(Heg)/2−Tr(Ht2g)/3`；四面体 `Δtet=Tr(Ht2)/3−Tr(He)/2`。符号保留，不事先假设哪组更低。显示子块谱和 `||P_A H P_B||F`；小混合仅是辅助诊断，不能证明最终 WF 轨道身份。
9. eV→meV 乘 1000，矩阵与谱同步换算，JSON 保留 eV 原值。

## 真实 Cr2FeS4_pri 审核

只读检索六个 Wannier 记录。25343/25344/25345 已结束，但未写出 hr.dat；25367 失败且没有该文件。本次实际测试为 25366 的无 SOC 54-WF 模型和 25368 的 SOC 108-WF 模型。后者已有 wout All done，但读取时本机调度状态仍为 RUNNING，未为测试伪造其完成状态。

原文件在来源服务器全记录校验、SHA256 和大小/mtime 前后核对，只回传 R=0 小快照与同前缀 win/wout/centres。测试快照明确标为提取物，origin.json 保存原文件 SHA、R 数与 R=0 原行号，不能冒充完整 hr 文件。无 SOC 还使用宿主实际来源合同运行独立后处理，结果可与快照逐项对照。

- 无 SOC：4 Cr×5d + 2 Fe×5d + 8 S×3p = 54。中心最大偏离约 0.06166 Å，解缠结有满足判据的记录；这些不足以确认 Wannier spread/带拟合及纯轨道身份。条件性 Δoct(Cr) 约 1.93710 eV，Δtet(Fe) 约 2.56195 eV。仅在声明的 WF 身份成立时作分组解释；不称最终物理晶场。
- SOC：108-WF，自旋交替展开；wout 明确写出解缠结判据未满足，中心偏离候选原子的最大距离约 1.89981 Å。保留复数矩阵/谱读取，物理模型判为待修正，不提供无 SOC 立方晶场。缺少 centres.xyz 时使用 wout 最后一组完整 Final State 的中心/展宽证据。另对两份快照逐 WF 核对最近原子对应的原胞平移，均为 14/14 原子内一致；这一检查仍不能证明最终轨道方向/相位身份。
- 本轮没有改 win、重新执行 Wannier90、运行 DFT、提交或取消调度任务，没有自动同步 GitHub。
