## 使用

左侧“问题记录”默认跨项目显示明确失败的 VASP 与 Wannier90 计算任务。按项目、程序、是否已备注筛选，或搜索项目名、节点名、错误、备注和 INCAR 标签。单任务、迭代 case、计算链步骤仍以各自 attempt 身份收录。同一来源只保留一个案例。

普通警告、UNKNOWN、容量等待及未收敛提示不会自动收录。在结果摘要、计算运行历史中点击“记录问题 / 编辑备注”主动加入；文件预览中选中日志文字，可记录当前文件与预览位置。末尾有限预览的位置不是原文件绝对行号。每个片段最多 8192 字符，每个案例最多 20 个片段。自动收录不抓取远端日志。

四项备注为用户备注、疑似原因、已确认原因、确认依据；确认原因须有依据。可附 INCAR 参数名，例如 `NCORE LCALCPOL`。旧任务备注 API 与集中记录共用注释；已有非空备注也会补收。案例保存收录时的名称、执行状态、有限回执和实际或冻结 INCAR/KPOINTS，排除 POTCAR 内容。原记录回收或删除后仍可查阅、编辑与导出；此时显示“原记录已删除”。这是经验记录，不是自动原因判定或新的提交门禁。

选中案例后可导出 Markdown 或 JSON。文件包含输入和用户选择的日志，属于用户本机研究资料；软件不会上传。

在“计算配置 → k 点、赝势与输入审查”中，手动网格旁有自动建议。选择初筛、常规、精细或自定义 `kpr`，先生成，再查看网格、中心、间距与约化前总点数，最后明确“应用建议到草稿”。生成不改网格；应用清除旧输入预览。手动修改网格或中心会移除旧生成依据。

| 档位 | kpr 范围 | 初始值 |
| --- | --- | --- |
| 初筛 | 0.06–0.04 | 0.06 |
| 常规 | 0.04–0.03 | 0.04 |
| 精细 | 0.02–0.01 | 0.02 |

使用完整晶格倒矢，`N_i = max(1, ceil(|b_i| / kpr))`，其中倒矢不含 `2π`。目标物理间距为 `2π × kpr Å⁻¹`；`kpr=0.04` 对应约 `0.251 Å⁻¹`，不能等同 INCAR 的 `KSPACING=0.04`。每方向支持 1–1000，超范围报错而不截断。

默认依据导入或编辑结构。下游未读取最终结构时明确显示“参考晶格”；已选择合格完成来源后，可显式读取其 CONTCAR。读取复用原有只读与缓存入口；密度选择、生成和应用均不探测服务器。项目、节点、结构、来源或选项变化后，旧建议失效，过期异步响应不能应用到另一草稿。冻结输入与活动计算链始终执行原明确网格；生成依据仅为可选元数据。能带路径保持独立。

新建议默认 Gamma；已有中心保留。六方与面心立方优先 Gamma；所有方向均为奇数时 Gamma 与 MP 相同，偶数方向有偏移。Gamma-only 为显式选项。真空方向是否设 1 由用户确认，不按长晶格自动判断周期性。密度档位不承诺计算精度；金属、DOS、SOC 和微小能差应检查目标量的网格收敛。Wannier90 的 `mp_grid` 是网格尺寸，必须与真实 k 点一致。

## 本地接口与兼容

- `GET /api/problem-records`、`GET /api/problem-records/{id}`：本机补收、列表、详情。
- `POST /api/problem-records/collect`：明确手动收录，可携带一个所选日志片段。
- `PUT /api/problem-records/{id}`：保存四项备注及 `incar_tags`。
- `POST /api/problem-records/export`：选择身份与 Markdown/JSON 格式。
- `POST /api/kpoints/suggest`：只读接收晶格、kpr、中心及 Gamma-only，返回网格与间距；不访问远端。

独立档案位于本机 `problem-records.sqlite3`，不受项目/任务清理删除。第一次启动补收旧失败与显式备注；新的 FAILED 状态持久化后尝试收录，收录异常只记录日志，不改变派发或调度状态。先手动记录、后来明确失败的来源会更新失败事实并保留注释。旧四字段备注接口、手动网格、冻结清单与授权仍兼容。
