# PyW90 手动调窗辅助：使用与验收

本包只改进 Wannier90 手动调窗的证据展示与采用流程。分析不修改远端研究文件、安装包或 .win，不冻结输入、启动计算或自动优化模型。

## 使用

在计算配置中选择 Wannier90 节点、已完成的 VASP-Wannier 来源及通道，点击“载入与审查 .win”，展开“绘图与 PyW90 数值辅助（按需）”。

1. 填写相对接口 OUTCAR 费米能级的分析范围，点击“检查当前草稿窗口与下界”。查看是否穿带、附近全局间隙、当前窗口四个边界及完整窗口逐 k 点态数。
2. `eig` 读取所选接口 .eig，保留原生外窗和冻结窗候选。外窗表展示 i_max、i+1_min、Nleast、Nmost，并给出间隙带号、宽度和中点。
3. `pre dos` 可使用同源的完成 DOS attempt。保留完整站点轨道归一化积分、阈值及选择结果，冻结窗表展示 N、pdos、tdos、percent。自动投影建议与当前 .win 模型分开显示；窗口计算使用当前 num_wann。
4. 点击候选或间隙中点的预览按钮，再次核验真实接口来源与完整窗口。预览显示四项参数的采用前值、采用后相对值及绝对值。约束失败时不能确认；通过后只填参数草稿，仍需显式点击“应用参数到 .win”。取消不改草稿。
5. 查看“原始命令、完整输出、警告与来源身份”复核来源。命令使用绝对能量，页面窗口数值统一显示 E−E_F（eV）。输出超限明确停止，不悄悄截短表格。

编辑草稿、分析设置或切换来源后，旧预览失效。上次检查报告明确标为过期；晚到响应不能覆盖新来源。

## 数值含义与边界

- PyW90 1.0.7 外窗下界来自全局相邻带间隙中点，按间隙上边缘筛选。中点可以低于输入分析下界，既不是最近位置吸附，也不是拟合质量排序。
- 原生 Nleast/Nmost 的区间是候选下界到 E_F。Nleast 是逐 k 点最小计数，Nmost 是能带范围与区间交叠的计数；原生冻结窗 N 也使用范围交叠计数，可能偏保守。
- 完整外窗／冻结窗另按接口 .eig 的逐 k 点本征值核对：每点外窗态数至少 num_wann，冻结窗态数至多 num_wann，冻结窗必须包含在外窗内。缺省四个边界按官方默认值解释。候选叠加到当前草稿后检查，不能单独检查半组边界。
- 全局间隙使用原生 0.004 eV 阈值，只说明已提供的接口 k 网格。高对称路径图可能漏掉其他 k 点的交叠；穿带本身不判定失败。
- `pre dos` 的自动轨道阈值为按最大单轨道积分归一化后大于 lb（默认 0.1）。pdos／tdos 评价自动选择的轨道贡献，不是拟合误差。当前函数数与建议数不同会提示，不自动修改投影或 num_wann。
- SOC／非共线 EIGENVAL 是单能带通道。XML 的 charge、mx、my、mz 分量不能解释为上下自旋 DOS；使用总电荷密度，空间轨道数乘二得到 spinor 投影建议，不假设 Kramers 简并。显式下自旋请求被阻止。
- 推荐为空、程序完成、态数检查通过、局域化收敛及物理模型可靠是不同结论。请继续结合 DFT／Wannier 能带对比和目标轨道判断。

## 实施

`pyw90_window_check.py` 是可直接送至登记远端解释器的只读检查器。`pyw90_adapter.py` 在进程内适配已安装 PyW90/pymatgen；临时目录只链接所选输入，原目录不产生分析输出。分析前后核对 OUTCAR、.win、.eig 及独立 DOS XML/EIGENVAL 内容身份。预览再次核对原候选接口身份，变化后要求重分析。

新增 `/api/wannier90/pyw90-window-check`；已有 advice 接口保留并增加完整日志、实际模型、来源身份和逐 k 点报告，返回 `fpilot.pyw90-advice.v2`。不修改任务来源、授权或派发合同。

## 验收

验收连接登记学校服务器，读取真实已完成接口与同源 DOS 输入，覆盖上、下自旋和 SOC；并在正式项目页面执行来源发现、载入、远端分析、采用前核验及取消。分析区间改变后，实际推荐轨道数与候选数相应变化，完整 126 行轨道依据及原生候选字段得到保留。真实 SOC XML 的四个密度分量复现了旧通道计数误判，修复后远端完整 pre dos 分析通过。

真实接口只读核验覆盖外窗态数不足、冻结窗越界和 SOC 当前函数数约束。分析前后来源文件身份保持；浏览器未应用参数到 .win、冻结或提交研究任务。私人日志、路径、项目 ID、原始研究数据及截图留本机开发备份，不随源码发布。

最终发布副本全量后端 569 项（3 跳过）、前端 100 项、类型检查与生产构建通过。正式服务按原 worker 配置重载，已有任务输入、冻结包及链／扫描授权单独核对保持。
