# 参数扫描待派发与取消状态恢复修复

## 修复范围

已受理的取消操作在远端 attempt 身份文件缺失后，旧逻辑会提前退出只读核查，导致已取消作业仍被本机计为运行中并占用候选节点。

宿主现在仅允许满足以下条件的恢复使用调度器 accounting：操作为 inspect、此前取消已受理、冻结身份绑定未变、取消时核对的所有者与当前用户一致。核查仍要求准确 job ID 及明确终态；队列中消失不等于结束。新的取消请求继续要求原目录和作业身份文件。身份不匹配、符号链接、所有者不符或未知终态继续拒绝；恢复不调用 qdel / scancel。

同时统一最终容量检查与预览：用户明确选择核数时，备注允许为空；没有明确核数时仍使用完整实时可用核数。繁忙、异常负载、节点不可用与最终资源漂移检查保留。

扫描摘要新增等待原因和派发错误。卡片显示中文批次状态与在途数量，已有在途项时不会把整批误示为待派发；暂停批次不显示过时等待提示。
