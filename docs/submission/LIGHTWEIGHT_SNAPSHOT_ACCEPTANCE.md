# 轻量项目快照传输

## 使用

两台设备都更新到支持快照传输的源码版本。在“项目概览 → 跨设备项目快照”选择已登记的同步服务器，填写独立的“快照保存目录”。计算工作区继续用于新建计算，两个设置不互相替换。

TiFe 已有库的位置是 **`$HOME/230269265lht/.fpilot/project-sync`**。Windows 的计算工作区可以仍为 `$HOME/fpilot`；快照目录应填写上述 Mac 保存位置。库内按项目 ID 建子目录。其他安全、可写的 `$HOME/...` 或 Linux 绝对路径也可使用，支持中文与空格；拒绝路径穿越、变量注入、符号链接及服务器根目录。更换地址不会搬迁或删除旧库，新地址没有快照时显示空库。

旧交接先点击“切换为快照传输”。完成状态可转换，本机暂停后续自动流程并恢复草稿编辑；未完成、回执不明或远端仍有操作锁时先核查原回执。转换保留原交接记录，不写原服务器快照。正式 TiFe 已通过此入口转换。

工位点击“上传项目快照”，核对实际路径、任务与附件数量，再确认上传。家里点击“读取服务器项目”，选择项目／版本，点击“下载并还原”并核对预览。未同步修改必须明确选择服务器版本；还原前自动备份，其他项目保持。JSON“导入为新项目”仍只用于复制草稿。

上传成功后可以继续编辑，服务器和目录选择框不会永久锁定。上传、下载均暂停尚未派发的自动链、扫描及分析，原授权保留；已排队、运行的作业继续跟踪。需要继续时使用链／批次原有继续入口，待执行分析使用“继续此暂停分析”。UNKNOWN 不重投，未开始分析才允许继续。

还原不要求所有计算服务器立即联网。后续刷新、准备或提交依旧按每个 attempt 的实际服务器、目录和精确作业 ID 核验。新设备需配置对应 SSH 别名；密钥路径可以不同，连接目标不能被偷偷替换。新计算所需的本机赝势等配置仍由本机登记。

## 数据和失败恢复

快照包含原项目／节点／attempt ID、草稿、冻结包、执行证据、链与扫描授权、备注、问题记录、已存分析和数据集附件。远端计算文件不移动，CHGCAR、WAVECAR、下载缓存、SSH 密钥、环境和赝势配置不入包。缺附件保留不可用说明，不自动分析；原始证据和冻结文件保持字节，只迁移本机运行元数据中的本机路径。无关的嵌套 JSON 参数文本保留原格式。

继续使用 SQLite 在线备份、不可变内容对象复用、版本／文件核验、项目传输锁和最新指针原子发布。单附件 256 MiB、项目附件 2 GiB 的既有限制保持。旧快照可读取；新模式使用 `fpilot.project-snapshot.v2`，旧客户端的 v1 预览拒绝新合同。两端不要混用版本。

项目锁串行本机派发和传输。暂停使用数据库写事务并更新 revision；worker 在项目锁内再次检查所属暂停计划，避免旧 ACTIVE 读值触发提交。分析重新读取状态后才启动。自动推进暂停和传输锁不是跨设备实时编辑合并，适用于一个人轮流工作。

上传失败也保留暂停。连接结果不明时“核查原地址的传输回执”只读核对，并释放已观察到的本机传输锁；不再次发布、不强占其他设备锁、不运行作业。还原中断不能作为成功，核查后只允许重新下载还原，完整备份保留。确认与恢复都使用原预览冻结的地址，不因当前选择框变化操作另一库。
