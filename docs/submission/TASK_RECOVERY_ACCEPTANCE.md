# 单项重算、剩余任务恢复与门禁简化 · 2026-10-16

初次开发于 2026-10-16 完成模拟验收；没有重投正式研究任务或发布安装包。后续真实项目验收、异步确认和候选节点池修复见 [2026-10-17 追加记录](RECOVERY_TIMEOUT_POOL_ACCEPTANCE.md)。

## 使用

- 参数迭代 case、Wannier 窗口 case、普通任务详情、链步骤均有 **提交此项 / 重新计算**。COMPLETED 只表示程序执行状态，不表示已收敛；不再因这个状态缺少重算入口，也没有“一次重试”的上限。
- 单项面板预填原输入、运行方式和资源，可修改 INCAR / .win、脚本、节点、核数、队列和时间。**检查并预览**显示各项输入差异与脚本，再一次确认提交。单项恢复保持其余项目原来的派发意图；暂停批次不会因此整批恢复。
- VASP 可选择沿用原来源、新电子态、仅结构、CHGCAR 或 CHGCAR+WAVECAR。relax 续算取 CONTCAR，其余阶段按实际 POSCAR；固定电荷阶段仍需 CHGCAR。Wannier 可原矩阵重算，或同矩阵、同 seed、同窗口的 .chk 检查点续算；检查点采用独立可写副本。
- 试投正常后使用 **提交剩余任务**，确认范围包含失败和未派发项，跳过在途、完成、取消和 UNKNOWN；UNKNOWN 必须单独确认。公共参数补丁只覆盖写出的参数，各 case 的扫描值保留；显式修改扫描坐标会生成关联派生 case。
- 每次明确恢复只推进所列项目一次。失败保留原因并继续其他独立项；不会由后台重复创建新 attempt。已授权但等待资源的原准备记录可复核后继续；这不等于重新发送一份不明调度请求。
- 读取恢复操作可查看原回执和等待原因；等待中的单项可 **调整此项并重新预览**，新确认替代原来的未提交意图。暂停后用 **继续本次已授权范围** 恢复相同范围。
- UNKNOWN 可在面板核查原任务；仍不明确时可确认可能重复后新建提交，原 UNKNOWN 和日志保持。也可只解除本机额度占用，继续跟踪原作业。

## 门禁变化

| 行为 | 当前处理 |
|---|---|
| FAILED-only、一次重试、BLOCKED 批次禁止单项恢复 | 移除；普通任务、扫描和链共用恢复实现 |
| 单 case 准备/提交异常、UNKNOWN | 记录在该项；其他独立 case 继续，额度仍按用户设置计算 |
| 链的未收敛或失败 | 停止依赖分支，等待明确恢复；不再隐式增加一次科学续算 |
| 取消一个任务 | 不再连带暂停整个计划；取消的待派发项不会从旧恢复意图复活 |
| 默认脚本/运行时改动 | 使用已保存配置；原脚本回收后可从快照创建独立恢复副本 |
| 输入、批次、Wannier 的理由 | 选填；不清除必要文件、结构维度和可解析性检查 |
| 手动未收敛/结束证据不足的来源 | 提示并允许明确确认；自动来源选择及链的上游收敛判断保留 |
| 整批结束后才能提升 case | 移除整批状态限制；所选 case 的科学证据判断保留 |
| 全局在途额度 | 各项可清空表示不额外限制；新工作区默认不限，已有设置保留 |
| 资源策略 | 默认等空闲；可改为直接提交调度器，忙碌、负载及诊断问题转提示；明确请求和既有资源声明保留 |

保留：不覆盖已有 attempt 目录、提交防重复、必要文件与实际来源一致、输入可解析、资源请求为合法数值、真实连接/目录明确、改变冻结输入或脚本后更新预览。调度器仍可能拒绝请求；收到 job ID 不代表程序完成或数值收敛。

## 实现与兼容

- `backend/task_recovery.py` 保存 PREVIEW / CONFIRMED / PAUSED / FINISHED 操作及逐项状态；确定性 attempt ID、计划锁与原提交锁共同避免重复发送。准备、提交和远端状态解析继续复用原实现。
- API：`POST /api/recovery/context`、`/preview`、`/{id}/confirm`、`/{id}/resume`，`GET /api/recovery/{id}`；`POST /api/execution/{id}/release-quota`。普通旧 retry 入口仍返回待提交准备记录；旧扫描 retry 转接单项恢复。
- 原冻结输入、attempt、job ID、输入差异与结果保留。修改普通参数保存同 case 的新输入版本；修改扫描坐标保存派生 case，避免旧坐标对应新输入。
- 快照包含恢复记录和其引用脚本。传输/还原后待提交恢复操作保持暂停；原回执继续可读，用户明确继续后才派发。含新恢复附件的快照需要支持该附件的工作台版本；旧快照仍可读取。缺失的恢复授权不能触发自动派发，可重新明确选择提交。
- 正式工作区没有数据迁移、额度改写或授权重启。源码备份、模拟回执和截图位于 `workspace-data/development-backups/task-recovery-20261016/`。
