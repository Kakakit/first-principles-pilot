# 远端分析稳定性与内置 PROCAR 读取

2026-10-21。本轮移除宿主对 VASPKIT 程序的执行依赖，修复 PyW90 路径读取的 HTTP 500 与无界等待。没有安装或升级服务器环境，没有执行真实远端 PyW90 或研究提交。

## 当前行为

- **投影能带**：工作台自有读取器直接处理 PROCAR，按元素、轨道与自旋生成数组，不生成 PBAND 中间文件、不启动 VASPKIT。逐行聚合，每次仅保留一条能带的元素权重，完整数组使用磁盘映射。SOC 只用第一组电荷投影，后三组磁化分量不相加。
- **大文件与缓存**：PROCAR 留在服务器，使用已有分析 Python/NumPy 执行同一份自有解析器。读取时同步计算 SHA-256，前后核对文件身份、大小、时间；与 EIGENVAL 核对自旋、k 点、能带数、坐标和能量。保留现有 10 MiB 传输边界与远端完整数组，不降采样。命中本机绘图缓存时不访问远端。
- **旧数据兼容**：PROCAR 存在时优先解析它；缺少时仍能读取完整的既有 PBAND。旧图表、缓存与目录不迁移、不自动重分析。旧 VASPKIT 生成及清理分支已删除，设置页不再提供 VASPKIT 路径。
- **同源 DFT 路径**：本机从已核对的 line-mode KPOINTS 提取，不再启动 PyW90。保留端点、顺序、分段与同源结构检查。目前仅转换倒格矢分数坐标；Cartesian 需转换或手动填写。bands_num_points 标为首段采样数，避免与 VASP 每段点数混淆。
- **基础窗口检查**：使用软件自有 .eig 检查器，不导入 PyW90、Pandas 或兼容适配器。原生候选、PDOS 建议与原生评分仍是可选 PyW90 功能。

损坏、截断、重复编号、缺失通道和不同源能量报告明确错误，不填零伪装完整数据。PROCAR/EIGENVAL 能量核对容差为 0.002 eV，坐标绝对容差为 2×10⁻⁶。这只核对数据配对，不代表数值收敛或物理有效。

| 分析锁无限等待，界面一直显示读取中 | 同步 PyW90 请求在占用时说明未发送；其他分析等待上限 300 秒；DFT 路径 HTTP 等待上限 180 秒，不自动重试 |

| 分析 Python 与 SSH 控制 Python 耦合 | 优先使用已有服务器默认分析运行时；未配置时兼容原解释器，不猜测、安装或激活环境 |

| 部分重型读取、渲染、传输走状态通道 | 统一走 analysis，保留独立状态核查；直接分析进程默认 BLAS/OpenMP 1 线程，显式核数优先 |
| SOC 评分先导入 PyW90 再判断不适用；报告硬写版本 | 提前判断 SOC；记录实际 Python、模块、版本和适配器修订，未知版本显示未报告 |

HTTP 超时只表示本机停止等待，不宣称远端程序已停止，也不重新发送分析或提交。既有 SSH 失败预算与手动恢复规则保持。

## 使用与职责

投影能带不需要配置 VASPKIT。大文件解析及内置窗口检查复用“设置 → 结果与扩展”的服务器默认分析 Python，与仅需标准库的 SSH 控制解释器分开。

可选 PyW90 功能在“设置 → 服务器与脚本 → 后处理工具路径”填写已有专用 Python 绝对路径。已装入该解释器时安装目录可留空；使用源码包时填写其父目录。点击“保存后处理工具路径”即可，不要求作业脚本、不测试连接、不准备任务。更换控制 Python 不再覆盖已明确配置的 PyW90 环境。配置保存不等于远端依赖已验证，本轮未自动改写用户服务器路径。

既有 PyW90 DOS 自旋/积分适配仍保留，没有冒称所有功能均为原生命令或已复制整个包进主体。进一步内置时应收敛为版本固定、函数接口明确的诊断组件，用现有上下自旋、SOC、积分和同源样例对照后再移除动态适配。复制包目录本身不能消除 NumPy/SciPy/Pymatgen 的环境依赖。本轮不新增后续优化迭代。
