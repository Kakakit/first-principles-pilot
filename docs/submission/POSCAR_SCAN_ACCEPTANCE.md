# POSCAR 晶胞缩放与固定体积迭代

## 使用

将参数迭代节点连接到一个 relax 或 SCF 基础计算，在“计算配置 → 参数迭代”把维度切换为“POSCAR · 晶胞缩放 / 体积”。填写起点、终点和步长，预览后冻结 case 表，通过现有运行审阅选择资源及确认授权。最多 4 个维度、64 个组合，可与 INCAR、U/J、k 网格组合；每个 case 保持独立输入和 attempt。

- **体积比 V/V₀**：例如 0.9～1.1、步长 0.02 得 11 个体积点，POSCAR 第二行写 `−V₀×比例`。
- **目标体积 / Å³**：填写正数，例如 95.049～116.171、步长 2.1122，第二行分别写 `-95.049` 等负数。它指定的是整个晶胞体积，不是每原子体积。
- **长度缩放因子 s**：晶格及 Cartesian 坐标同时缩放，体积比为 s³。例如 1.01 对应 V/V₀=1.030301。

V₀ 来自基础计算的当前生效结构。相连上游 relax 使用所选合格 CONTCAR；SCF 使用实际 POSCAR；结构节点使用已验证文本/几何。每批先只读核验一份基准，再让各 case 独立缩放，不累计乘前一个 case 的比例。已有正 scale、负目标体积及三分量 scale 先解析为实际晶格和坐标，再生成新 scale，避免使用未缩放晶格而产生错误体积。保留原子 ID、顺序、分数坐标、Selective Dynamics 和磁矩；含晶格速度或预测校正段时明确阻止独立体积扫描。三分量 x/y/z 的文本编辑继续可用，本入口扫描均匀缩放。

**负 scale 只指定初始体积。** 固定体积结构优化可用 ISIF=4（改变形状和离子位置，保持体积），或 ISIF=2（保持晶胞，只优化离子位置）。基础节点参数不会静默改写；允许体积变化的 ISIF 会在预览顶部醒目提示。因此不要把 ISIF=3 的初始体积序列直接当成固定体积 EOS 点。

## 来源和历史

独立扫描支持新计算及上游结构/CHGCAR 自洽初值，不读取 WAVECAR，不套用同节点/未完成优化续算。电荷初值仍按既有参数差异、几何及磁化密度审核；几何不同按初值外推说明。每个 case 冻结具体来源 attempt 和原始结构身份；准备/派发继续核查来源。缩放后的 POSCAR 已保存在冻结包内，原始 CONTCAR/POSCAR 作为核验基准，派发文件计划不会再次复制它覆盖缩放结构。

预览表显示实际体积、V/V₀、输出 scale、基准体积及作业号，差异详情包括 POSCAR；文件核验身份收进技术详情。文件去重同时比较 INCAR、KPOINTS 和 POSCAR。基准文件或来源选择变化要求重新预览。UNKNOWN、暂停及受阻的历史逻辑保持，不自动提交。

现有项目、结构节点、冻结包及远端任务不会批量修改；只为新批次增加 `fpilot.poscar-scan.v1` 的几何记录，沿用 VASP 批次和来源 v2 合同。无需复制大量结构节点；批次结果可作为已有 EOS 扩展的多任务来源。

## 验收

用 Ce 相变研究的真实 gengzi-187 / 22807 CONTCAR，只读核验 V₀=105.60992221042669 Å³。隔离项目副本预览及冻结 0.9～1.1 的 11 点；逐字核对冻结 POSCAR、体积、负 scale、来源、原子身份和 ISTART=0 / ICHARG=2；核查派发文件计划为空，原始 CONTCAR 不会覆盖新 POSCAR。浏览器验证体积比、绝对体积、长度因子、错误值、草稿保存重载及运行审阅入口，不授权研究提交。

专项覆盖两种坐标、正/负/三分量基准 scale、非正交晶格、约束及磁矩、组合维度、重复/超限/非法数值、来源变化和 UNKNOWN/WAVECAR 阻断。测试证据和私人副本在本机 `workspace-data/development-backups/poscar-scan-20261012`，不发布研究数据。

语义依据：[VASP POSCAR](https://vasp.at/wiki/POSCAR)、[VASP ISIF](https://vasp.at/wiki/ISIF)及[官方固定体积教程](https://vasp.at/tutorials/latest/bulk/part2/)。
