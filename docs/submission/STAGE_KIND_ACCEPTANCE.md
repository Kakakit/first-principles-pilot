# 阶段编号、VASP 草稿类型切换与节点界面

## 使用

新建项目按类型使用固定前缀：structure 01、relax 02、scf 03、bands 04、dos 05、vasp-wannier 06、wannier90 07、scan 08。例如删除 SCF 后再次添加，仍是 `03-scf`。同类型节点可共用阶段目录，每次运行由节点身份和独立 attempt 目录区分；自定义目录后缀保留。

新项目记录 `stagePolicy: kind-fixed-v1`。没有这个标记的旧项目不迁移、不重新编号；旧项目新增节点继续使用原规则。模板、独立分支和“导入为新项目”使用新规则；备份恢复和跨设备接续保留原规则与身份。

在流程画布选中 VASP 节点，在节点设置选择计算类型，查看参数、阶段目录和连接问题后确认。仅 relax、scf、bands、dos、vasp-wannier 之间可切换。已有冻结、准备、执行、冻结来源、计算链或扫描引用的节点需先复制；回收区仍保留的历史也参与检查。复制不带连线、任务授权、历史来源绑定或旧审核确认，物理参数和输入草稿保留。

relax → 静态类型会明确设置 `NSW=0、IBRION=-1`。反向切换保留已有正数 NSW 与合法优化算法；不足时 NSW 留空，IBRION 使用 2，等待用户填写步数。切换可撤销，但节点新增冻结或执行历史后不能通过撤销更改历史类型。旧项目切换保留编号，默认后缀随类型更新；原目录不移动。

新建、复制和独立导入的静态节点补齐缺失的静态默认值，显式草稿值保留并继续审核。NSW/IBRION 可编辑、清空；值与类型不符时阻止冻结。VASP-Wannier 默认 NCORE=1，页面明确显示现有接口合同的 NCORE/KPAR/ISYM 实际值；保存的旧草稿值仍保留，差异明确提示。

底部任务记录占位栏及节点历史草稿展示已移除；历史数据未删除。“检查流程”改为弹窗，可点击问题定位节点。

## 接口与兼容

- `GET /api/projects/{project_id}/node-editability` 只读返回节点 `can_switch` 与具体阻断 `reasons`，不探测或创建远端目录。
- 保存工作区时重新核对类型变化；旧项目不能改编号策略或在切换时改变编号。历史节点被移除后，以相同 ID 恢复时必须匹配历史合同类型。
- 冻结包的完整图快照不会锁定无关节点，只核对合同直接引用。损坏或无法读取的历史返回核查失败，不把它当成没有历史。
- 绘图候选增加 `node_id、execution_scope`；名称按实际身份匹配，避免同阶段目录的不同节点被误认。旧结果缺名称时使用类型与作业号。
