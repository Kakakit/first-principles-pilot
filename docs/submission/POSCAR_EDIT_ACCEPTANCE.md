# POSCAR 文本编辑与 EOS 晶胞缩放

## 使用

在结构页选择节点，点击“编辑 POSCAR 文本”。修改完整文本，先“验证并预览”，确认体积、晶格、原子数量和元素顺序后“应用到结构节点”。错误保留编辑文本，取消不改结构；应用后可到计算流程使用“撤销”。现有几何与约束编辑入口保留。

第二行一个正数是长度因子；负数的绝对值是目标体积（Å³）；三个正数缩放晶格和 Cartesian 位置的笛卡尔 x/y/z 分量。Direct 分数坐标不乘 scale。各向同性缩放体积按长度因子的立方变化；1.01 对应体积比 1.030301。重复编辑同一份文本时，当前结构已含此前 scale，不会自动重置到原文件。

标题、晶格、元素、数量、坐标类型、坐标、Selective dynamics 和可识别附加段可编辑。速度、晶格速度及预测校正内容随执行文本保留；不识别或截断的附加内容拒绝应用。原导入字节始终可下载。

原子数和元素序列不变时按坐标行保留原子身份，缩放不会丢失 MAGMOM 映射。重排原子须选择“重新建立原子身份”；元素或数量改变时自动重建，并提示重新核对磁矩、Hubbard 和 POTCAR。不会按位置猜测旧参数的新归属。

“导出当前 POSCAR”与生成输入使用同一内容。后续几何表单编辑替换文本，仅生成几何与约束。历史来源提供实际 POSCAR/CONTCAR 的节点仍遵循现有来源规则；本次修改不覆盖历史冻结输入或远端任务。

## 接口与兼容

`POST /api/structures/poscar-edit` 接收 `parent、text、rebuild_atom_ids`，返回 `structure、summary`。此接口只验证提案，不写项目或派发任务。结构新增可选 `poscarText`，原 `source` 保留；旧记录不迁移，旧缓存 POSCAR 继续由几何重新生成。

保存和输入生成重新解析显式文本，以 1e-10 绝对容差核对晶格、长度、角度、体积、两种坐标、元素顺序和约束。差异停止生成/冻结，要求重新验证。复用已登记 pymatgen，通过薄适配层支持三分量 scale，并修复负 scale + Cartesian 的位置解释，不升级依赖。
