文件与日志：新增删除操作

在“结果与后处理 → 文件与日志”中，为所有普通文件添加“删除”。由用户逐个确认，方便清理 CHGCAR、WAVECAR 等大文件。

已实施的方案记录；此页面按钮仅作示意，不执行操作。使用与验收记录

1. 界面与确认流程

文件（示意）操作
OUTCAR
CHGCAR / WAVECAR沿用现有预览及下载限制
  • 输入、输出、检查点、证据和其他文件统一提供删除；每次只操作一个文件。
  • 先只读核查，再展示完整路径、主机、attempt、文件大小、任务状态及下游引用。默认聚焦“取消”，明确确认“永久删除此文件”。
  • 切换项目、节点或 attempt 后旧确认框关闭。成功后移除文件行和该文件预览，再刷新清单。

这是永久删除，不放入同盘回收站。本机已下载副本、冻结包及历史记录保留。硬链接或仍打开的文件可能不会立即释放全部标称空间。

2. 删除条件与下游影响

  • 活动任务禁止删除。完成、失败和 UNKNOWN 都须实时核查；无法证明停止时禁止删除，队列中查不到任务不能单独作为停止证据。
  • 被下游引用的文件允许明确确认后删除。保留原计划与授权，后续所需文件缺失时停止；不自动换来源、重投或取消运行中的下游。
  • 仅删除受控 attempt 内的普通文件，拒绝目录、符号链接、链接祖先和路径穿越。使用本机保存的身份绑定；远端身份标记存在时必须匹配。

3. 后端接口与一致性

  • POST /api/execution/{id}/artifact-delete-preview：只读核查，返回影响说明、操作 ID 及有效期 10 分钟的令牌。
  • POST /api/execution/{id}/artifact-delete：匹配项目、文件、身份及明确确认；令牌至多执行一次。
  • GET /api/execution/{id}/artifact-delete/{operation_id}：只读核查已删除、未删除、冲突或待核验；连接中断不自动重删。
  • 与派发共用跨进程来源锁，执行前重查状态、引用和文件身份。大文件只核对设备号、inode、大小和精细时间，不下载内容。
  • 保留最小回执并失效文件与来源缓存。删除成功但刷新失败时显示“已删除，文件列表待刷新”。

4. 验收与交付

  • 覆盖大小文件、全部类别、中文/空格路径、链接、越界、身份替换、过期令牌、重复请求、调度状态变化和断线恢复。
  • 验证引用提示、下游缺文件停止、缓存失效以及历史和授权保留；浏览器使用一次性文件，真实研究项目只读核查。
  • 完成专项与全量回归、前端检查及构建，更新检查点和验收记录，再按既有流程增量同步 GitHub。
  • 提交标题：为文件与日志新增单文件删除，核验任务状态与下游引用。
