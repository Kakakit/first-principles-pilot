# 计算链首次授权立即派发 · 2026-10-09

确认整链授权后，先持久保存原有授权，再立即通过与 worker 共用的派发入口准备并提交首批可执行节点。首轮无需等待 300 秒监控周期；后续节点、容量等待和显式继续仍沿用原 worker 周期。没有资源时保留 PENDING，有明确等待原因。

HTTP 与 worker 使用计算链级跨进程文件锁，保留确定性 attempt 身份、在途额度、提交事务和远端提交一次保护。同一授权请求再次到达时只返回原记录；不同请求不能覆盖已授权计划。暂停期间不覆盖 PAUSED，不提交其他起点；已开始提交的原作业仍保留 job ID。回执丢失保留 UNKNOWN，不自动重投。

接口沿用原授权请求。返回链记录增加可选 initial_dispatch（IN_PROGRESS/FINISHED、开始/完成时间），本机 GET 返回步骤的 attempt_state 和 job_id。GET 仅投影已有记录，不写链、不核查远端。旧冻结输入、历史授权和旧请求保持兼容。

提交页显示首批准备进度、作业号、等待上游、等待额度和容量原因。首次派发期间每两秒读取本机 GET，首轮结束停止；无重叠请求，切换项目/链及较旧响应不会覆盖当前记录。授权响应断开后读取同一份记录，不自动重复 POST。

验收：

- 隔离后端全量 481 项，3 项按既有环境条件跳过；2 项本机端口用例在沙箱外补跑通过。新增 9 项覆盖多起点、上游、容量、额度、重复授权、跨进程互斥、暂停、UNKNOWN 及首轮中断后的 worker 接手。原 CPU/GPU、来源和历史授权合同回归通过。
- 前端 96 项、类型检查和生产构建通过。发布副本另通过计算链相关后端 42 项、前端 93 项及类型/构建。
- 实际隔离 HTTP 服务未启动 worker，授权请求约 0.024 秒后进入第一步准备；模拟两次准备各延迟一秒，两个起点都返回 job ID。重复 POST 没有额外提交；并发本机 GET 显示 IN_PROGRESS，不改变链 revision。该数字验证派发时机，不代表真实服务器耗时。
- Safari 原生选择冻结链、检测模拟节点、候选池、确认、首批进度和作业号通过。补充浏览器验证最终主题、等待上游和两秒 GET，首轮结束后停止短轮询。模拟作业及证据留在本机，不进入真实研究项目。

仅增量同步本轮源码与公开说明。没有提交真实测试计算、重投 UNKNOWN 或恢复暂停队列；正式服务按原设置重载。既有 47 个 attempt 的输入/脚本/资源和 9 条链的计划/授权保持，worker 仍使用 300 秒周期。私人配置、研究数据、模拟夹具、截图和其他未发布工作保留本机。
