# 通用目录、脚本导入与原样命令

2026-10-16。本轮更新源码，不生成安装包或 Release。

## 路径与兼容

- 设置“通用默认工作区”只影响之后新建的项目，新建窗口可直接修改；服务器在实际提交时选择。项目保存自己的根目录，冻结输入固定该值。优先级：单服务器项目绝对目录覆盖 → 项目通用根目录 → 旧服务器根目录。默认 `$HOME/fpilot` 可改，HOME 在所选服务器解析；也可使用 `/scratch/my-projects` 等绝对路径。
- 新目录使用英文命名。显示名称、备注和日志可用中文；历史非英文路径仍可读取，不重命名、不迁移。没有 fpilot、个人账号目录或 material-projects 名称白名单。旧项目缺少新字段时继续原 material-projects 布局。
- 只读探测使用实际账号的读写权限，不创建目录或修改权限。确认后才建本次独立 attempt，已有 attempt 不覆盖。外层项目目录已有普通内容可共用，明确的其它项目身份记录仍阻止混用。

## 脚本与命令

- 导入不要求 PBS/Slurm 头，不审核程序名、硬编码 MPI、GPU 字样或 trap。资源字段能识别时可编辑，不能映射时选择“原样脚本”。主动选择 GPU 资源编辑时必须能映射 MPI 数量，避免界面与实际不一致。
- Windows 临时文件写完先关闭，再原子替换；失败保留原文件，仅清理本次临时文件。文本持久化明确使用 UTF-8，兼容中文备注和本机用户目录。
- 其它/自定义预设保存名称、备注及多行命令。确认页展示最终目录和命令，执行副本仅统一 Linux 换行。按普通来源/输入流程准备文件，再后台 Bash 运行；不调用调度适配器或 PBS/Slurm 容量门禁。
- 每次运行独立保存回执和分段 stdout/stderr，保留退出码。COMMAND_EXITED 只表示命令结束，不代表外部队列或科学计算完成。回执不明保留 UNKNOWN，只读读取原 ID，不自动重发。查询/取消预设由用户明确运行，不解析队列语义。custom 不自动推进链/扫描，PBS/Slurm 原流程保持。
- 系统 OpenSSH 沿用配置、密钥类型、agent、跳板和会话复用；软件进程须能免交互执行命令。每次仍需验证码的连接须先建立可复用会话，本轮不新增内嵌验证码或终端。远端要求 Bash 与 Python 3.8+。
- PyW90 解释器和包目录逐服务器配置，没有固定主机或个人安装位置，不自动安装。
