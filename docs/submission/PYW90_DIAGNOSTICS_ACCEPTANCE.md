# PyW90 诊断校准、窗口界面与叠图指标

日期：2026-10-19。范围仅为手动诊断和能带叠图；不新增自动迭代入口、优化器或计算派发。原研究目录、输入、历史比较和已安装 PyW90 源码保持原样。

## 使用方式

1. 在 Wannier 窗口页面选择“检查当前窗口”“外窗候选”或“冻窗候选”，再点击对应检查／分析按钮。切换标签本身不访问远端。分析范围用于生成候选；当前手工窗口按草稿中的四个边界检查。
2. 冻窗比例使用当前 `.win` 的明确投影集合；复杂投影不能可靠映射时，可在折叠的数值选项中明确填写 PDOS 集合，例如 `Fe:d`、`Fe@0:p`（站点编号从 0 开始）。不能映射时显示原因，不擅自换成自动建议轨道。自动轨道建议单独折叠展示。
3. 默认采用同一三次样条的直接积分；高级选项保留 Gauss 300。页面同时显示当前手工冻窗比例、实际轨道集合和积分方法。采用候选仅复制窗口边界，不改 `num_wann` 或投影。草稿、来源或方法变化后，旧结果标记过期并禁用采用。
4. 生成 DFT–Wannier 叠图时自动给出主误差和 PyW90 原生评分。图像先可用，原生评分随后补充；缺包、不适用或评分失败保留图和主误差。已有图直接读取本机记录，不因打开页面而重新分析。
5. “评价范围与目标带段”独立控制统计范围、分组大小和 DFT 起始带号。首次比较建议并固定连续带段；同一 DFT 来源、通道和模型维数沿用该基准。修改带号产生新的基准版本，旧图不回写。默认每组 6 条带，可导出 PNG、SVG、曲线 CSV、诊断 JSON、逐带和分组 CSV。

## 数值口径

- DOS：沿用原生 `splrep(..., s=0)` 的三次插值，默认直接积分其 BSpline。每条不同曲线仅拟合一次，窗口积分复用。输入网格须有限且严格递增，积分范围取数据域交集；非正 TDOS 不生成比例，超出 0～100% 的结果原值保留并提示。
- 主误差：固定 DFT 参考带和 DFT 采样网格，各路径段内线性插值 Wannier 能量，不跨断开的路径插值、不平滑。仅按 DFT 参考能量选择评价范围；偏离范围的 Wannier 误差仍计入。MAE、RMSE、最大绝对偏差使用 meV，同时记录样本数。参考带不完整时保留局部统计，不输出可与完整覆盖混用的总分。
- 原生评分：调用已安装 PyW90 的原生 AbAk，独立自动匹配 DFT 带，保留 unit 能量核和 9 点／2 阶 Savitzky–Golay 平滑；单列原生匹配带段、版本和评价范围。该分数与未平滑主误差不是同一口径。SOC、参考带不足或采样不足时明确不适用。
- 所有显示窗口和图注均为同一 DFT 能量参考下的 E−E_F。小误差不证明解纠缠收敛、局域化或物理有效性。

原生 DOS 使用五点积分是已核实的代码事实；未找到作者对其精度取舍的明确说明，不能断言是有意设计或疏忽。直接积分解决同一插值函数的求积误差，不证明原始 DOS 能量网格已经收敛。候选生成规则保持，积分不会创造候选表之外的手工窗口。

## 结构与调用量

| 职责 | 位置与行为 |
|---|---|
| DOS 数值与投影映射 | `backend/pyw90_dos.py`，纯数值，不触发传输或提交 |
| PyW90 适配 | `backend/pyw90_adapter.py`，进程内替换积分；一次读取 XML，一次读取 EIGENVAL，生成冻窗报告 |
| 共用误差 | `resources/extensions/pyw90/scripts/comparison_metrics.py`，仅数组运算；既有扫描调用薄适配，原派发／排名合同保持 |
| 诊断记录 | `backend/wannier_diagnostics.py`，本机基准版本、表格和缓存 |
| 原生评分 | `backend/pyw90_score.py`，从已缓存数组调用库，不重新扫描 `.eig`、XML 或 `.wout` |
| 绘图与展示 | `backend/wannier_compare.py`、`src/WannierComparisonResult.tsx`，先落图再补评分，详情折叠 |

对照：冻窗报告从两次 native pre 调用合并为一次结构化调用，XML 和 EIGENVAL 各解析一次；原生评分从独立 pre band／cmp／来源读取改为一个有界库进程，仅消费已缓存数组。优先本机已登记解释器；仅本机缺包且远端运行时已就绪时走既有分析通道。默认数学线程为 1。相同请求运行中合并、完成后复用，失败不自动重试。
