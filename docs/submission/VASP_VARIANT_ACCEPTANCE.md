# 同目录 VASP 程序切换 · 2026-10-08

已导入的常规 VASP 原稿可以用于 SOC／非共线任务，无需手动改写后再次登记。程序选择仍由冻结输入决定；原稿分类、身份和字节保留，只在本次执行副本中将 `vasp_std` 切换为同目录的 `vasp_ncl`。原有独立非共线脚本与显式登记方式优先保留。

设置与提交选择器显示可复用原稿及切换说明。单任务、参数迭代和计算链的确认预览显示程序差异；计算链的常规与非共线步骤可以引用同一个原稿 ID，逐步骤冻结最终脚本。GPU 原稿继续使用原 GPU 请求、MPI 数量、设备及整节点策略。

适配范围是一个明确的 VASP 启动命令：绝对路径、目录变量路径、PATH 命令，以及启动前唯一赋值的程序变量；支持常用 mpirun/mpiexec/srun 参数。变量名、环境加载、库路径、MPI 和输出文件名不作全局替换。PATH 命令从原程序所在目录定位目标；启动前检查目标文件可执行，缺失时退出并给出程序名，不退回常规版本。多次启动、未知包装、动态/重复赋值或分类冲突会给出明确缺项。

这些能力不代表目标程序已经完成本次运行验证。预览保持本机渲染，编辑不新增远端探测。`vasp_gam` 不自动选用；其适用输入仍需独立审查。[VASP 官方编译说明](https://vasp.at/wiki/Installing_VASP.6.X.X)列出三个构建版本，[非共线说明](https://vasp.at/wiki/LNONCOLLINEAR)要求使用 `vasp_ncl`。
