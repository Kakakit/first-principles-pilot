## 2. 计算来源与冻结合同

- “电荷、重启与输出”中的统一来源区：新计算、同节点重启、已连接上游，设置中的高级手动来源。源选择决定 ISTART/ICHARG；表单中的对应值只读显示，消除两套可变配置。
- 上游默认最新合格 attempt；明确选择不可用的来源时不回退。候选根据本机保存的结束/电子/离子证据、冻结物理输入与文件清单检查，不在打开页面时 SSH 或扫描大文件。冻结时主动核对实际文件。
- 同节点读取电荷重算保留当前有效 POSCAR；继续未完成 relax 使用来源 CONTCAR。默认 CHGCAR，明确选择两文件时才要求 WAVECAR，不静默降级。新计算的纯结构传递不额外要求 CHGCAR。
- 冻结合同按结构、电荷、波函数角色保存精确 attempt、主机、路径、核验策略与文件元数据。小型物理输入保留内容身份，大文件沿用轻量策略。冻结后不替换为最新结果；准备与提交重新检查原来源。
- 准备接口读取冻结合同，禁止另传可变依赖/续算覆盖它。结构与电子角色分别物化；可写电子文件仍独立复制/写时复制并校验目标大小。
- 未来链上游绑定计划节点，worker 使用该计划产生的准确最终 attempt。扫描保存自身来源草稿、冻结身份和批次 scope；case 包不进入基础节点的单任务选择器，后端也拒绝错误入口。旧 case 身份从批次记录只读识别，不改历史包。
- Wannier90 新增输入独立冻结、历史列表和冻结 ID 准备；`.win`、通道、能窗、矩阵与能量参考绑定后，运行页不得用新草稿替换。

## 3. 服务器绑定与历史兼容

- `execution.sqlite3` 持久保存执行分支 RESERVED/BOUND。实际远端文件依赖合并分支，本机初始结构与 scan 的参数模板连线不合并；同批扫描使用独立 scope。
- 准备不永久绑定。原子派发事务先预留，准确 scheduler job ID 后永久绑定；FAILED 不解除，UNKNOWN 保留预留。单节点、重试、链/扫描 worker、Wannier90 和绘图续算共用检查。
- 派发前读取当前画布连线，新增连接冲突阻断派发。回执只绑定派发前预留的成员；后来画布改变不阻断已提交任务的监控。
- 新准备/授权记录保存该主机/程序的设置快照。运行时或默认模板改变后，旧准备或尚未派发授权阻断并提示重新审查；其他主机/程序设置及历史监控不受影响。旧记录不追加快照或改变原合同。
- 唯一历史服务器自动识别；多个历史服务器在设置中显式整理终态旧记录归属。原 attempt 字节不改，运行中、UNKNOWN 或已有新绑定不能解除。
- “复制为独立分支”生成新项目、节点和连线身份，复制本机结构/参数/流程，清除远端来源、授权和绑定。副本通过完整工作区校验；原分支和远端目录不动。
- 旧冻结、PREPARED、授权和来源不批量迁移。旧续算包需返回配置重新审查；旧正常历史与监控继续可读。
