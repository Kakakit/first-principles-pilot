# 画布多选与计算链点选 · 2026-10-07

## 2026-10-08：Safari 真实项目回归

用户反馈 Safari 多选拖动后画布变空白。现场确认仅画布为空，项目导航和详情仍存在；受控节点忽略 dimensions 更新，选择/详情/拖动重绘时丢失 measured，内置浏览器可复现 React Flow 015 节点未初始化警告。官方 [NodeChange](https://reactflow.dev/api-reference/types/node-change) 与已安装库的 adoptUserNodes 合同要求接回节点尺寸。

FlowCanvas 现在缓存按项目隔离的节点测量尺寸，并接回每次受控节点投影；计算链只读模式也接受尺寸反馈。删除的扫描子节点和其他项目的尺寸不复用，相同尺寸不触发额外重绘；无效尺寸与非有限位置不进入保存。原始项目节点、研究参数与撤销快照不包含尺寸缓存或界面回调。

真实项目包含 18 个节点、16 条连线。内置浏览器完成两个节点同步位移、API 保存回读及一次撤销，两节点均恢复测试前位置，无新增 015 警告。Safari 原有空白画布恢复为完整节点/连线/小地图；原生自动拖动工具只能触发拖动开始，未产生实际位移，因此未将其计为成功。随后用户在 Safari 手动重复原多选拖动操作，明确确认“已经可用”。保留用户之后手动调整的布局。

80 项前端用例、类型检查和生产构建通过。新增回归使用实际 React Flow 内部节点接纳及位置计算，覆盖选择、连续移动、撤销、扫描尺寸变化、子节点清理、项目切换和尺寸反馈幂等。后端未修改，不重复 Python 全量。真实计算输入、运行记录和授权保留，没有从测试触发远端探测、提交、恢复队列或重跑。真实工作区快照、保存回执和截图只保存在本机 development-backups/canvas-drag-fix-20261008，不上传 GitHub。

## 使用

- 主流程画布：普通点击单选；Ctrl/Command 点击增选或取消；Shift 按住后从空白处拖出框选。拖动任一选中节点可移动整组，一次撤销恢复整组位置。点击空白清空，多选集合与右侧详情焦点分开。
- 计算配置页选择“计算链”：沿用项目布局、节点卡片与连线，点击计算节点切换“本次执行”，可全选、清空，并显示数量。支持 Enter/Space 操作，缩放和平移可用；此画布不改位置和连线。
- 首次进入默认选中所有受支持节点，执行范围仍限于 relax/scf/bands/dos/vasp-wannier。结构、参数迭代与独立 Wannier90 节点只作流程上下文。
- 取消上游不会把它重新加入执行范围。预览仍审查历史来源；确认复用的节点标记“复用历史结果”。缺少合格来源时不能冻结。改变范围清除旧预览、来源绑定与脚本预览。
- 冻结后锁定范围。点击“重新选择节点”建立新的配置草稿；原冻结计划和授权留在历史中。

## 实现边界

App 的详情焦点与画布多选分开管理。选择只存界面，位置仍走原工作区保存；拖动开始只记录一次撤销。FlowCanvas 复用编辑与计算链选择模式，保留现有连线及 case 展示。计算链将当前受支持的选择按项目顺序传入现有 node_ids，不改变后端 API、数据库、来源检查或派发流程。

没有增加批量删除、跨程序调度，也没有对原计划执行暂停、恢复或重新授权。未发布新的运行 ZIP。
