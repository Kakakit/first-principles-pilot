# 页面内存、连接恢复与编辑稳定性 · 2026-10-18

本轮处理三维结构切换后的资源残留、列表与图表重复分配、SSH 失败后频繁连接，以及保存提示导致输入框跳动。保留原项目、冻结输入、attempt、服务器目录和结果，不发布安装包或 Release。

## 使用变化

- 三维视图随页面卸载释放独立显示上下文；切换结构复用当前 viewer。
- 概览读取轻量状态，常用运行历史每页 50 条；选中后才读取完整脚本、输入和回执。旧完整接口仍可使用。
- fatband/PDOS 进入可见区域时绘制，离开后释放；导出逐图绘制并释放临时图表，通过 PNG 二进制保存图片与同一份曲线 CSV。连续点击只启动一次导出。
- 草稿停顿 1 秒合并保存，离开输入框、页面隐藏或明确“立即保存”时保存最后修改。保存串行使用磁盘版本号，不用保存回执重新填充表单。失败后保留草稿，并在设置中处理冲突或重试。
- 保存状态固定在底部，不在表单上方插入／删除提示。类型核查保留已有结果，复制入口固定显示；异步核查不再反复推移名称与备注框。
- 删除概览、结构、参数、比较、后处理等页面重复的开发说明和实现细节；来源与详细说明放入已有折叠区，单位、必要错误和影响计算选择的提示保留。

## SSH 与状态

首次连接失败后进入 15 分钟冷却，最多额外自动恢复 5 次；第 5 次失败后暂停该主机的自动连接。设置页、普通请求、worker、兼容通道和旧绘图流式下载共享持久状态；重启不清空预算。手动检测仅检测一次，成功后恢复跟踪，不重新提交作业。

同主机按普通／分析通道限流，不再立即重放失败的只读命令；过期的排队请求不会补发。队列、在途载荷和日志尾部有内存上限。流式下载直接写入临时文件并核对原大小／哈希，不把大文件装入 JSON。Windows 的一次性 OpenSSH 调用使用 argv，无需本机 Bash。

worker 按主机并行检查，同一主机的已有 job ID 合并读取调度状态；运行期间不反复扫描完整 OUTCAR。终态和无法从调度器确认的记录继续使用原核查。连接失败保留最后状态与科学证据，另记核查错误和时间；旧调度快照不能回退已结束状态。UNKNOWN 保留，不自动重投。

## 验收

在原有解释器与锁定 Node 依赖上验证，使用 5 项目、68 节点、113 attempts 的真实工作区副本；隔离 API 与网页只监听 127.0.0.1:19268–19270，并强制禁止 SSH。一次性脚本、截图与私人回执归档在开发备份中，不提交仓库。

- 真实 14 原子结构连续切换 50 次：原版 `resize/mouseup/touchend` 各从 1 增至 51；新版父页面保持 1 个消息监听器和 1 个 iframe。Safari 原生同样完成 50 次切换。WebKit 不暴露标准 JS heap 数值，本轮不声称测得精确总内存降幅。
- Ce 项目 44 个 attempts 的概览响应从 1,205,475 字节降至 74,438 字节，约减少 93.8%；历史第一页 63,967 字节。
- 真实上下自旋能带与 PDOS 四图：初始 0 个图表 Canvas，滚动到末尾为 1 个，导出后仍为 1 个。导出 PNG 1024×3494、1,343,260 字节；CSV 59,901 行数据，PNG／SVG／CSV 均保存成功。
- 真实节点备注输入、停顿保存后，最终生产构建 textarea 的 y 坐标均为 534.6796875 px，文字与焦点保持。测试结束还原副本备注。
- 持久冷却、跨进程读取、5 次预算耗尽、崩溃租约、手动恢复、主机隔离、过期队列、连接目标变化、终态保护、分页、二进制导出、流式 argv 接收与失败清理均有针对性回归。
- 用户授权的真实只读测试：jutai-1 两次 printf 使用 1 个 SSH 会话，首次启动约 9.76 秒，复用请求约 0.12 秒。另一次流式 printf 只读检测 16 字节接收一致（约 9.60 秒）。主动验收共启动 2 个 SSH 会话，未提交研究任务。
- 活动源后端全量 770 项（3 跳过）、前端 145 项；筛选上传副本后端 756 项（4 跳过）、前端 142 项；两份源码的类型检查与生产构建通过。后端专项 41 项通过。上传副本跳过：第二解释器也具备 jsonschema、未携带研究 POTCAR、未安装 httpx、未携带历史 Wannier 样例；相关科学样例不上传仓库。

Safari 原生驻留 1,806 秒（30 分 6 秒，含前后台切换），50 次切换后未重载；父页面消息监听器、外观监听器、iframe 均保持 1 个。最终生产构建另行完成中文输入／保存验收。隔离服务与临时页面已关闭，正式服务保持运行。

正式工作台已按原 worker 开关启动，间隔仍为 300 秒；113 个 attempts、6 个批次、7 条链的身份与非跟踪字段逐项相同。此前暂停／冻结的计划继续保留。gengzi-187 原 UNKNOWN 的首次核查和第 1 次自动恢复均超时，状态进入冷却，持久计数在重启后保留；未创建新 attempt。

## 证据边界

本轮修复了可以复现的显示资源残留和重复分配，不据此断言 Safari 所有重载都只有同一原因。原 gengzi-187 诊断显示 ZFS 路径访问阻塞，不能据此精确断定当前停在 chdir，也不能把 SSH 登录失败计数直接当作本软件连接次数或存储故障原因。PAM 的失败登录提示来自失败登录记录，归因仍需服务器认证与存储日志。
