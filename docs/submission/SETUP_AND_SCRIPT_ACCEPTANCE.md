# 首次服务器配置、脚本库与提交编辑验收

2026-10-05。用户授权实施及 GitHub 同步后的源码交付。使用现有 OpenSSH、脚本库和派发流程；没有新增远程调度系统。

## 如何使用

1. 设置 → 服务器与运行：选择本机 SSH 别名，读取配置。没有别名时展开操作指引，追加自己的 Host 配置，复用已有密钥或使用独立新文件名。在终端确认服务器指纹、完成认证。
2. 点击“测试免交互连接与服务器工具”。成功后显示实际主机/账号/端口、已有 Python 3.8+ 和调度器；未找到 Python 时展开高级路径填写。调度器不符时要求用户核对并选择。测试也检查工作区的最近存在父目录和权限，不创建目录或执行脚本。
3. 默认保持“导入可用任务脚本”，登记服务器。上传/粘贴普通 VASP、SOC/非共线、Wannier90 或其他分类的脚本；来源默认采用文件名/名称。保存默认值是可选操作；临时选择不会改默认值。
4. 提交页选择冻结输入，再直接选择本服务器、本程序的脚本，编辑名称/队列/walltime，检测节点并选择核数，准备后核对最终脚本并确认一次。链按实际 std/ncl 程序各选一份脚本；扫描固定本轮选择。

新服务器的根目录默认 `$HOME/fpilot`，支持其子目录、含 `fpilot` 的专用绝对目录及原登记根组件。现有服务器与旧 attempt 不迁移。准备阶段只读取最近存在父目录；确认派发后核对准备时的绝对路径，再创建根目录和 attempt。根目录、相对路径、已有目标及项目所有权检查保留。

## 编辑与脚本边界

名称、walltime、核数、理由、同服务器脚本或根目录变化保留节点事实与合法选择，清除旧预览/确认。队列和分区按已发现规则校验。切换服务器/调度器清除旧节点；有效 SSH 主机、账号、端口、跳板或密钥配置改变时，后端拒绝旧准备记录，并切换连接会话。输入过程中没有 SSH 查询或自动轮询。

节点检测仍是时间点观测。准备/授权会自动复核，最终派发在一次非重放远端请求内再次校验实时容量、队列/分区与时间上限。临时繁忙不调用调度器，保留草稿；UNKNOWN 留原记录核查、不重投。链和扫描沿用候选池等待机制。

脚本中的 source、module、MPI、程序路径作为运行来源，不要求在登录节点重现计算节点环境。脚本模式不执行“高级路径是否存在”的预检；控制通道仍使用已登记的真实 Python 绝对路径。连接测试使用 BatchMode，关闭连接复用，避免已建立会话掩盖认证问题。

- 原稿不可变，修改生成关联副本。执行副本规范 Linux 换行。
- PBS 混合 `-l` 行保留 mem 等未编辑资源。重复/无法映射的资源不能静默适配。
- 明确固定 MPI 进程数与请求核数不符、进入固定/未知目录（含提交目录后的逃逸后缀）、已有 trap，给出具体适配提示。
- Slurm 单节点纯 MPI 使用 ntasks；线程、特殊任务/GPU/多节点布局需要适配，不承诺额外调度支持。
- 新导入脚本不自动把 std 改成 ncl；分类与明确程序冲突会阻断。旧记录继续使用其已有合同。
- 已准备或已授权的新任务冻结实际脚本与运行方式。修改全局默认值不改写这些任务；旧准备记录保留原快照规则。

静态检查覆盖明确资源与执行证据冲突，不能代替通用 shell 分析或目标计算节点的实际运行验收。导入脚本和连接通过不构成计算成功或数值收敛的证据。
