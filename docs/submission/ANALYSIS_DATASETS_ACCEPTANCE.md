# 后处理结果数据集 · 2026-10-09

## 使用

左侧“数据集”与项目内“数据集与历史交接”使用同一结果库。进入“历史分析”，按项目、分析类型或名称查找已完成结果，直接查看并选择“登记到数据集”。也可在对应后处理结果旁登记。默认名称包含项目、来源节点、分析名称和时间，可修改名称并填写备注。

登记后可从“已登记数据集”查看、搜索、编辑名称与备注、下载结果。支持 V2 扩展、V1 后处理、旧极化与旧本机分析绘图；原有已保存交互图、能带比较和电子结构结果库继续使用原记录。

只手动登记明确完成的分析，不补收失败、不适用或待核查记录。查看历史、登记和搜索只读取本机数据，不运行分析或探测服务器。

## 保留与接口

- 按来源类型与分析 ID 去重，重复登记返回原快照，不覆盖原结果。标题、备注与数据集自己的展示设置可单独更新。
- 保存来源名称、分析版本、原运行配置、完成状态、警告、科学验证状态，以及已在本机的结果文件和就绪交互展示。单文件沿用 10 MiB 上限；未回传、缺失或过大的文件明确说明，不读取远端大文件。
- 登记文件按清单读取并核对；V2 主结果须与原分析记录一致。登记过程中来源变化会中止并清理临时快照。
- 删除或回收原任务、分析、项目后，登记快照仍独立保留，并显示原记录已删除。快照自身可移入统一回收站和恢复；永久清理只针对该快照。
- 新接口 `/api/analysis-datasets` 提供历史候选、登记、列表、详情、文件、元数据和展示设置。旧电子结构数据集接口与格式保持。
- 界面丢弃过期列表、详情和保存响应；开发服务忽略数据目录中的 HTML 写入，避免登记交互快照导致页面重载。

## 边界

登记表示保存已有分析结果，不提高其数值或科学验证结论。缺少就绪交互展示时保留原始表格、曲线或文件预览；不会自动生成展示。旧结果按现有文件提供 JSON、CSV、Markdown 文本和图片的适用预览与下载。真实扩展的数值与物理结论仍需根据原证据判断。

GitHub 采用原 main 的增量提交，仅发布本轮源码与本文档；历史提交不改名、不重写。研究结果、私人配置、验收夹具和日志留本机。旧运行 ZIP 未重打包，需从更新源码构建。
