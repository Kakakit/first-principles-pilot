# PyW90 路径写入与调窗信息层级

## 行为与兼容

修复共享 PyW90 执行回执被当成字符串解析的问题。配置页与已有模型的补画入口均解析 stdout，保留命令及警告；无效回执、空输出与失败返回具体原因。非 JSON 响应显示 HTTP 状态，网络断开仍单独提示。

路径可在标量参数未应用时获取和写入。写入只修改 bands_plot、bands_num_points、bands_plot_format 与 kpoint_path，参数表中的未应用增加、修改和删除保留；原文尚未解析时保留提案，解析后再应用。失败可编辑和重试，重新载入与参数应用从最终 .win 同步能带状态。请求期间锁定来源和通道，避免把返回结果写入另一个来源。冻结仍要求所有草稿变化已应用。band-path/apply 兼容原请求及 win 字段，增加最终绝对参数 parameters；路径提案增加 pyw90_run，不改变旧冻结合同。

诊断摘要放大 num_wann、完整外窗最少态数、完整冻结窗最多态数及穿带状态；窗口边界、间隙带号和能量边缘、原生 N/Nleast/Nmost 默认可见。原生计数与完整 .eig 逐 k 点计数分开，相对边界为 E−E_F / eV，绝对边界保留在核对详情。采用预览突出变动边界。比例表示所选轨道贡献，约束通过不表示最佳拟合；算法、顺序、能量精度和原始输出保持。

## 验证

真实服务器的同源 DFT KPOINTS 提取九段路径，40 点采样设置。上下自旋当前实际输入均可合并，标量参数和受保护结构字段保持；已完成模型的独立 restart=plot 输入可生成，未准备或提交补画任务。

专项后端 79 项（1 项历史样例跳过）、前端 7 项通过。发布副本全量后端 580 项（3 项既有跳过）、前端 104 项及类型／构建通过。两项旧来源测试的 PyW90 回执更新为实际执行记录形状；端口用例在允许本机回环绑定的环境完成。

浏览器核验配置页和已有模型补画入口均取得真实九段路径、40 点设置。未应用 num_iter 保留且未进入最终 .win；无效坐标显示明确原因，修改后可重试。原文未解析时保留提案，修正与解析后可写入；上下自旋草稿隔离，重新载入保留各自参数与路径。请求期间来源不可切换。

上自旋、下自旋和 SOC 的真实分析回执显示验收通过：摘要 24 px、窗口与原生 N 18 px，带隙位置与完整计数默认可见；方法、126 行轨道积分及绝对能量详情可展开。真实下自旋的原生 N=53 候选同时显示完整冻结窗最多 60、超过当前 54 的原因。采用前预览继续调用真实窗口核验接口，并突出改变的边界，取消不采用。五套主题可读；325 px CSS 窄屏保留两列重点卡片，表格独立横向滚动，页面无横向溢出。

正式服务按原配置重载，71 个任务、11 条链、2 个扫描批次与 148 个冻结文件的身份、输入与授权核对保持；暂停、受阻及 UNKNOWN 状态保持，worker 健康且仍为 300 秒。

业务核验使用真实项目及服务器；显示验收使用已有真实 SSH 分析回执，未生成模拟数据。页面参数操作在项目隔离副本中验证，原研究输入、冻结记录和检查点保留。一次性脚本与私人回执留在本机开发备份，不随发布上传。
