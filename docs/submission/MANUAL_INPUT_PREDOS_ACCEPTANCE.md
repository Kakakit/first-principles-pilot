# 自由参数文本与矩阵生成前的投影诊断

## 使用

“物理参数与继承 → 低频与自定义”提供共享层、节点层的手动 INCAR 文本。文本覆盖同层表单值，节点层优先于共享层；删去手动赋值后恢复表单或继承值。搜索用于插入模板，不再要求未知 tag 逐项确认。注释、分号赋值、反斜杠续行和双引号内多行内容沿用同一个小型解析器；没有新增编辑框架或依赖。参数名称和取值不做目录审核，最终结构、文件来源、初始化与接口一致性仍核验，冲突明确报错。

Wannier90 使用已有完整 `.win` 编辑器。自定义 tag 和参数块原样保留，解析后同步可识别的表单值；VASP 生成的结构、k 点、自旋与矩阵维度保持。原文窗口为绝对能量，表单窗口为相对费米能量。旧冻结、attempt 和研究输入不改写。

VASP-Wannier 的“Wannier 投影”先展示独立 PyW90 pre dos，再展示完整 Projections 文本及 NUM_WANN。投影不限制 s/p/d/f，也不拆词、不改大小写或要求全部元素参与。自动计数仅处理完整的简单“元素:s/p/d/f”集合；出现中心、杂化、具体分量等表达时停止估算，保留手填值。

## pre dos 的准确依赖和含义

普通 `pyw90 pre dos`（没有 `--extra`）只使用 `vasprun.xml` 的站点轨道 DOS；不需要 `.win`、接口 `.eig`、矩阵或 `EIGENVAL`。PyW90 原生添加 `--extra` 的另一条分支才读取 EIGENVAL 并生成冻结窗建议；本入口不运行该分支。原有 Wannier90 完整调窗入口继续核对实际接口 `.eig`，两种用途独立。

工作台另读同一来源 OUTCAR 的 E_F，将用户 E−E_F 范围换成绝对能量。分析前后核对 OUTCAR/XML 内容身份。原始轨道积分复用 PyW90 的积分方法，保留最大积分归一化分母、归一化值、lb 阈值、所选轨道、原始命令与警告。建议依据是指定区间的轨道权重；它不判断最佳局域化，也不证明拟合质量。共线上下自旋单独分析，SOC/非共线使用电荷投影，建议函数数按 spinor 计数。

只从相连 SCF 或同一 SCF 来源的已完成 DOS 中选择；没有投影 DOS 时显示具体原因，不用其他输入拼出建议，不自动补算。缺少登记的 PyW90 环境时提示配置，不安装软件。建议由用户主动替换投影，可撤销；不会自动改 NUM_WANN。来源或范围变化后不能采用旧结果。
