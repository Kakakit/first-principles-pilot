# 跨设备项目接续

## 使用

在 **项目概览 → 跨设备项目接续** 选择已登记的服务器。工位先保存草稿，预览后确认“上传并交接”；家里登记指向同一服务器与工作区的 SSH 别名，点击“读取服务器项目”，预览后“下载并接管”。无需事先导入 JSON，也不用重新认领远端目录。

现有 JSON 导入继续复制草稿、生成新 ID；接续入口保留项目、节点、attempt、精确 job ID 和远端目录。服务器只保存快照与设备归属，不安装常驻程序。文件内容身份用于附件复用，最新指针验证后原子发布；旧版本可选择恢复为只读，不抢占执行权。

同 ID 接续前自动备份本机项目。存在未同步修改时必须选择服务器版本；不自动合并。其他项目保留。完成交接后，原设备草稿只读，手动、链和扫描新派发受共同设备检查约束。已有排队、运行任务继续；接管保留原授权，暂停／受阻／UNKNOWN 不恢复或重投。

## 快照范围与身份

包括项目草稿、独立冻结 ZIP／Wannier 配置、执行及事件、分支绑定、链／扫描和原授权、问题记录及备注、已保存分析／图表／独立数据集、相关回收标记及单文件删除回执、已使用脚本模板。本机分析目录内的已存附件随包保留；原本缺失的附件显示不可用，远端附件不会伪装已下载。原始输出及独立数据集证据保持字节和文件 hash，只有运行元数据中的本机路径迁移；冻结包与原来源、授权不改写。

CHGCAR／WAVECAR 和原计算输出留在服务器。下载／投影缓存、临时文件、开发备份、SSH 密钥及设备 Python／赝势库配置不入包。新冻结仍需配置本机赝势库；已有冻结输入包完整保留。附件超过单文件 256 MiB 或项目 2 GiB 时明确拒绝上传，不静默遗漏。

快照使用 [SQLite Online Backup API](https://www.sqlite.org/backup.html) 后按项目取行，不复制在线数据库文件。接续数据库、问题记录和工作区索引在附加数据库事务中更新；附件逐文件原子写入。替换前保留完整项目备份；中断后执行门保持停止，不能将部分导入当成成功。

服务器路径：登记工作区下 `.fpilot/project-sync/<项目 ID>`，包括 `objects`、`versions`、`state.json` 和操作锁。本机恢复副本：工作区 `project-sync/backups/<项目身份>/<备份身份>`；已被服务器版本省略的原附件另存 `project-sync/retained-local-files`，不遗留在活动分析列表中。

两设备的 SSH 私钥路径可以不同；接管及派发核查实际服务器、用户与根目录身份。原授权中的连接记录保留，通过只读适配验证同一目标。不同服务器／根目录阻止。未启用同步的项目沿用既有流程。

分析 worker 也遵守设备归属。已开始的远端分析保留原作业供跟踪；迁移时尚待执行的分析、原设备未完成的本机分析标为 UNKNOWN 并保留原状态，不在新设备自动重跑。已保存结果原样保留。

## 停止和核查

每次派发从预检、物化到 qsub／sbatch 持有服务器项目操作锁，交接使用同一把锁。本机跨进程项目锁同时串行草稿保存与派发。服务器操作锁不按超时强行抢占；回执不明先“核查同步状态与回执”，不重发上传发布、接管或提交命令。

核查仅在确认本机没有 DISPATCHING、远端操作属于本机时释放已完成／中断的本机锁。其他设备锁或仍待核查的派发保持停止。首次上传未发布时，核查后允许重新预览上传，仍不恢复自动派发。

“刷新远端记录”只核查快照中已知 attempt 的受控目录、身份标记、精确 job ID、任务状态及文件清单。目录缺失保留记录与提示；不扫描认领其他目录，不据此解释为未提交。刷新属于读远端、更新本机观察，不能替代数值或物理审核。

## 验收记录

专项覆盖两个不同根目录的工作区、原 ID／原目录／历史／冻结授权／分析备注保留、独立数据集证据 hash、缺附件、附件复用、版本陈旧、本机修改保护与备份、重复下载、预览过期、历史只读恢复、目录及文件链接、错误来源／job 身份、两 worker 的互斥、上传未完成、发布及接管回执丢失、不重发 UNKNOWN，以及观察设备只读草稿。

真实 `Cr2FeS4_pri`／`Cr2FeO4` 仅收集本机范围并只读核验已知远端目录身份。学校服务器的实际上传／下载／交接使用新建隔离 `sync-acceptance` 项目及中文 CSV；未运行 qsub／sbatch，未修改研究 attempt。

最终来源／分析接续专项 57 项通过。按 GitHub 现有版本叠加本包后的发布副本，全量后端 559 项通过（3 项跳过），前端 98 项、类型检查及构建通过；登记服务器与固定脚本夹具只在本机提供，不发布私人配置。

浏览器验证服务器项目发现、上传／下载预览、取消、本机未同步修改确认、保存草稿后交接、旧设备只读、版本列表刷新和历史版本实际恢复。学校 SSH 验证两工作区附件往返、归属接管与旧设备派发阻断；大文件继续留在计算目录。

正式服务按原配置重载，新接口可用，worker 健康且周期仍为 300 秒。原 65 个任务、11 条链、2 个扫描批次的输入／来源／授权身份和 136 个冻结文件核对保持；既有暂停、受阻与 UNKNOWN 状态保持。研究项目未启用同步，也未提交研究计算。

私人任务、服务器回执、一次性验收脚本和截图只留本机开发备份，不随 GitHub 发布。增量发布只包含本包代码、测试与说明，其他未分配改动保留本机。
