# Wannier 参数、单参数窗口测试与叠图保存

## 交付内容

参数目录载入实际 `.win`，空字段／默认下拉可删除旧 tag；应用前显示新增、修改、删除。最终原文统一用于解析、审核、冻结和准备，相对窗口从最终绝对窗口和已核验费米参考推导。原文解析同步表格，未应用改动阻止冻结；受保护的结构、维度、k 点和自旋信息保持。草稿按来源与通道保存到项目，复制为独立项目清除绑定，接续快照保留；删除不会被旧字段缓存恢复。

参数分为常用、折叠高级收敛／插值、折叠算法／日志、输出文件。来源和能量参考、fatband／PDOS 与 PyW90、路径输出在输入参数之前，应用与冻结在底部。restart 的既有检查点限制保留。

参数迭代读取相连 Wannier 节点当前草稿，任意单边界的范围或列表最多 64 值。新 v2 批次准备时保存不可变基线／case 输入，再经资源与脚本授权；旧 v1 包与授权保留。完整 `.eig` 逐 k 点返回态数，官方缺省语义、错误候选和来源变化明确报告。结果仍由用户判断并采用到新草稿，不自动最优化或重投 UNKNOWN。

叠图可填写标题，历史和新叠图可命名、备注并登记到独立数据集；保存 PNG、SVG、CSV、任务来源、窗口和能量参考，旧记录补读已核验冻结输入，重复登记打开已有数据集。中文图题使用本机可用 CJK 字体；中文图题依赖设备已有 CJK 字体，本轮没有安装新字体。

页面以节点名称、通道、备注、时间和作业号展示版本与来源，内部 ID 与哈希保留于技术详情。扩展新运行仅 local/ssh，无调度资源表单或新调度执行；旧清单声明不赋予执行能力，未启动调度预览拒绝，已启动历史只核查原任务。

## 实际业务验收

- 真实学校服务器：共线上下自旋及 SOC 单通道 `.win/.eig/.amn/.mmn`，每条通道均为 216 个 k 点。验证从外窗下界、冻结窗上界开始，无手动基础冻结；错误外窗候选逐项说明；删除冻结上界后按官方语义禁用冻结窗。
- 使用实际矩阵来源，在隔离 SQLite 中准备两 case 的 FROZEN v2 批次；基线、case 内容身份和执行 scope 核对，各 case 没有 attempt 或授权。未申请资源或提交计算。
- 用已完成实际 DFT／Wannier 输出生成中文命名叠图，保存 PNG、SVG、CSV 到本机验收目录。正式项目原历史叠图在浏览器中预览、取消、命名和登记成功，独立数据集文件完整；再次打开使用同一数据集。
- 正式浏览器：新增 num_iter 后清空显示删除，应用后原文无该 tag；原文修改同步表格；恢复原草稿并切换上下自旋重新载入，删除未恢复，通道分别保存。页面先辅助后参数，底部应用／冻结；实际矩阵单参数列表预览通过，未准备正式研究批次。
- 浏览器来源和版本使用人可读名称，扩展入口只有本地与服务器直接命令行。未改变原研究输入、矩阵、checkpoint、冻结包、授权或暂停／受阻／UNKNOWN 状态。

单元回归覆盖删除与注释、原文实际参数、保护字段、范围和缺省窗口、64 值限制、来源变化、不可变 case、独立数据集复制／重复登记、禁新调度及旧 UNKNOWN 只读恢复。单元夹具只检验合同，实际业务验收使用真实服务器与实际记录。

## 验证和运行边界

工作区专项 100 项、首轮全量后端 584 项（3 跳过）、前端 106 项及类型／构建通过。最终发布副本全量后端 578 项（3 跳过）、前端 103 项及类型／构建通过；发布树基于既有远端基线，只叠加本轮任务增量，其他未分配改动保留本机。真实计算未新提交、暂停／受阻记录未恢复，新的拟合质量仍需用户通过独立批次审阅授权后计算。

正式服务按原配置重载，原 68 个任务、11 条链、2 个批次和 145 个冻结文件合同／内容身份保持，worker 健康且间隔为 300 秒。私人来源、一次性验收脚本、截图及详细回执留本机开发备份，不入 GitHub。
