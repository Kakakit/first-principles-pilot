# VASP 来源合同 v2：规则、验收与边界

2026-10-10。统一新计算、同节点重启、上游依赖的来源规则，手动冻结、链内绑定、历史复用和一次条件续算共用后端来源引擎。保留既有 SourceDraft 入口和旧运行证据。

## 实际生效的规则

| 场景 | 实际结构 | 默认电子读取与初始化 |
|---|---|---|
| 结构节点 → relax / SCF | 配置结构 | 新电子态，ISTART=0、ICHARG=2 |
| relax → relax / SCF | 已达到最终电子、离子收敛的 CONTCAR | 默认新电子态，0 / 2；可显式选择 CHGCAR 初值 |
| SCF → relax / SCF | 来源 attempt 的实际 POSCAR | CHGCAR 自洽初值，0 / 1 |
| 相连计算节点上的“新计算” | 保留相连上游的实际结构 | 新电子态，0 / 2 |
| 同节点读取电荷重算 | 所选历史运行的实际 POSCAR | CHGCAR，0 / 1；可选兼容 WAVECAR |
| 继续未完成优化 | 所选历史运行的 CONTCAR | 按冻结策略读取电子文件；使用 WAVECAR 时，固定晶胞为 ISTART=1，连续变胞优化为 2 |
| bands / DOS / 现有 VASP→Wannier 固定电荷入口 | 合格 SCF 的实际 POSCAR | CHGCAR 固定电荷，0 / 11 |

静态节点不要求 CONTCAR 或离子收敛。仅继承结构不审核 SOC、ISPIN、MAGMOM 等电子差异；仍核对结构完整性和有序元素。读取 CHGCAR 后才审核电子模型差异；自洽初值允许网格、ENCUT 等改变，固定电荷的泛函、U、赝势和实际几何不同会阻止使用。WAVECAR 另外检查 k 点输入、实际文件头的 NBANDS/自旋通道、完整性及准备阶段的带并行；明确不兼容不能通过确认绕过。

共线到非共线重启保留官方支持；读取既有磁化密度时，MAGMOM 不重新设置原子磁矩，共线磁化沿 SAXIS 解释。使用 ISTART=2 的连续变胞优化不允许改变 ISIF / ENCUT / PREC 来冒充同一次续算。几何比较采用晶格绝对差 1e-6 Å、周期分数坐标差 1e-6；字节身份单独核对。

## 冻结、缓存和执行

- 新冻结记录 `fpilot.source-contract.v2`，区分尚待绑定的节点和已绑定的文件角色，保留具体 attempt、结构原文身份、核验方式与 ISTART / ICHARG。准备记录 `effective_input` 和最终 INCAR，包含条件续算的实际修改。
- 来源清单记录观测状态、主机/路径/冻结身份和时间。运行期、旧格式、截断清单只表示待核验；参数编辑与来源候选检查保持本机。显式刷新才读取文件清单；冻结和派发重新核对必需文件及结构身份。结构预览按同一清单身份失效。
- 电子判断使用最后一个 OSZICAR 数值步，旧 OUTCAR 标记不能覆盖末步未收敛。离子判断只接受最后一轮的收敛证据。已授权链最多一次条件续算：SCF 从实际 POSCAR、CHGCAR、WAVECAR 续算；relax 从 CONTCAR 和冻结的兼容电子策略续算。再次不收敛、缺文件或 UNKNOWN 停止该分支，下游只绑定成功续算的具体 attempt。
- LCALCPOL 在生成、冻结、准备与派发前检查有效 PEAD 并行。CPU 的明确 NCORE≠1、同时指定 NPAR/NCORE 会阻止；准备和派发结合实际 MPI/KPAR 检查 NPAR。提示修改参数或资源并重新预览，原包不改。
- 参数差异确认仅用于可审阅的电子变化。界面显示实际文件、初始化、核验状态及分级原因；输入页和冻结链显示当前草稿与旧计划的具体差异。重新冻结后新参数才进入执行输入。
- 能带路径和网格建议都读取同一个实际结构角色。保存和重新载入保留路径来源文件名，不再要求静态 SCF 额外生成 CONTCAR。
- 可写 CHGCAR / WAVECAR 使用 reflink 或独立复制，来源文件保留。旧 v1 冻结包、历史 attempt、授权只读适配，不重写输入，不恢复暂停/受阻链，不将 UNKNOWN 当作未提交。

## 验收证据

本机私有最小复现来自本轮成功的只读远端核查与保留的原始回执，证明了：SOC 结构继承误拦截；首次 SCF 达到电子步上限后重算成功；终态实际非空文件被旧零字节缓存误排除；旧极化包 NCORE=6 与当前草稿 NCORE=1 不同；节点名称与实际 SOC / ISIF 不一致。隔离复现通过结构角色绑定、实际 POSCAR 身份、新极化输入准备和独立 CHGCAR 复制。后续追加读取遇到 SSH 超时，没有声称取得新的远端证据；CHGCAR 格式舍入夹具按此前测得的舍入误差重建，未复制或验收完整电荷网格。

最终全量 Python 510 项通过（3 项跳过），新增及最终来源合同 16 项通过；前端 99 项、类型检查与生产构建通过。基于远端完整树构造的发布副本：相关后端 119 项通过（真实材料夹具 1 项跳过），前端 96 项、类型检查与构建通过。发布副本不依赖私人服务器登记，调度测试使用已有解释器的隔离替身。

真实浏览器使用独立 Si 工作区、禁用 worker、阻止实际提交。核对来源选择、旧零字节清单待核验→显式刷新、SCF 实际 POSCAR/CHGCAR、冷启动 0/2、电子差异确认、新冻结保留旧版本、NCORE 6→1 的旧包及旧链提示、重新冻结后的差异消失，以及网格建议实际 POSCAR。自动续算、UNKNOWN 不重投、固定电荷未收敛、真实缺文件、结构错序、舍入容差、波函数不兼容及旧 v1 适配由必要合同回归覆盖。

研究记录核对范围为原有 52 个 attempt、10 条链、2 个扫描批次、全部既有冻结 ZIP 和本机配置；实施没有提交真实研究任务或恢复暂停队列。截图、原回执、私有夹具和一次性脚本归档在本机 development-backups/source-contract-v2-20261009，研究数据、POTCAR、服务器配置和这些私有材料不上传。

调度终态、程序正常结束、数值收敛和物理有效性仍是四类不同结论。本轮修复软件来源与派发合同，没有完成材料的物理验证，也没有替用户重新提交旧失败任务。
