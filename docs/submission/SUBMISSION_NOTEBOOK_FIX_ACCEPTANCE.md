# 提交诊断与问题记录删除验收 · 2026-10-09

计算链准备提交时保存逐阶段、逐候选节点预览，再显示具体阻断原因。容量等待仍可授权，缺失脚本、资源合同或静态配置错误继续阻止授权。确认页按节点展示原稿与本次单节点资源脚本的差异，单任务预览也提供差异入口。不改变既有冻结、派发或历史授权合同。

服务器连通及有空闲节点并不能证明脚本适合当前输入布局：工作台把输入放在 attempt 目录，脚本须进入调度器提交目录；计算链沿用单节点整机资源，PBS 原稿须使用单节点申请。本机已按用户要求保存关联副本并更新新草稿默认，环境及启动程序保留，原稿及历史保持；私人脚本不发布。提交时选择修复后的副本，预览会按所选节点总核数映射资源。

问题列表与详情均增加删除入口。删除移入“已删除记录”，保留任务、四项备注及证据，可恢复；默认列表与导出排除已删除记录。自动 FAILED 收录及启动补收尊重删除标记，后续失败不把已删除记录加回；在原计算结果中主动“记录问题”可恢复同一份档案。备注保存再次检查删除状态。旧分析档案继续留在本机，不进入计算任务问题列表。

问题页使用明确的 flex 高度与纵向滚动区域，卡片、过滤器与动作行允许换行；选择列表末尾问题后滚动到详情，长证据保留内部滚动。

验收：

- 隔离后端全量 472 项，3 项按环境跳过；2 项临时端口用例受沙箱限制后单独补跑通过。相关合同 91 项（1 跳过），前端 94 项及类型/生产构建通过。
- 缺少可选 httpx 的环境以标准库 HTTP 验证实际列表、删除、重复补收、已删除列表及恢复端点；未安装依赖。
- 浏览器模拟 25 条长记录，滚动至末尾、读取详情、删除、恢复及原备注保持通过。Safari 原生上下滚动、删除、已删除列表与恢复通过。未删除真实问题档案。
- 本机修复副本经 bash 语法、标准/非共线程序预览及整节点资源核对；原稿 hash 保持。没有提交测试计算，调度及程序真实执行仍以实际任务证据为准。

发布副本另通过 91 项相关后端（1 跳过）、91 项前端及类型/生产构建，513 个既有远端源码文件身份核对后叠加本轮改动。短窗口 800×560 验证页内滚动和底部备注保存可达，无横向溢出。

只增量发布本轮源码和此说明。私人脚本、问题证据、备注、模拟夹具、配置及研究数据保留本机。
