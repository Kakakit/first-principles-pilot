# 服务器登记移除、带边信息与软件图标

## 使用

在“设置 → 服务器与脚本”选中服务器，点击“移除此服务器登记”。预览列出本机任务记录数量；默认聚焦取消。确认仅移除本机登记，可在“已移除的服务器”恢复。SSH 配置、服务器目录、已提交作业、任务历史、脚本及默认值保留。派发中的服务器暂不可移除；移除后新派发停止，历史状态与文件读取继续使用保存的解释器信息。不会选择其他主机替代提交。

能带节点的“结果与后处理 → 绘图与后处理”增加 VBM、CBM 和 CBM−VBM。复用现有 OUTCAR 提取结果；相对值采用图的同一个 E_F，绝对值放在核对详情。相连 SCF 来源标注“SCF 网格”，本任务来源标注“能带路径”。数据缺失或无可识别的正带隙时显示未提供，不按当前显示范围猜测边界，也不据此判定金属性。采样点上的边界不是全布里渊区或物理带隙的保证。

统一青绿色 F＋晶格标记的 SVG/PNG/ICO/ICNS。Windows 安装器、桌面/菜单快捷方式、卸载入口显式使用 ICO；快捷方式与启动进程采用同一 AppUserModelID。Mac 安装应用和开发入口通过 CFBundleIconFile 引用 ICNS。安装图标采用 [Inno Setup 图标设置](https://jrsoftware.org/is6help/topic_iconssection.htm) 和 [Apple 应用登记约定](https://developer.apple.com/library/archive/documentation/Carbon/Conceptual/LaunchServicesConcepts/LSCConcepts/LSCConcepts.html)。浏览器窗口仍由用户选用的浏览器管理。

源码目录首次 `npm run dev:launcher` 生成唯一 Mac 开发应用，后续双击启动。模板放在 packaging/macos/dev-launcher/，生成物忽略于 Git，普通开发副本不再携带应用包。图标可用已登记开发 Python 运行 packaging/icons/generate.py 重新生成；无需创建环境或增加应用运行依赖。

## 目录整理与恢复

45 个旧验收目录压缩到 workspace-data/development-archives/。归档前后逐文件 SHA256 与链接目标一致；移除展开副本前再次确认内容未变。11 个重复应用路径定向注销，Mac 应用索引只保留活动源码目录的一个带图标入口。旧目录合计 1,830,890,017 字节，压缩包合计 707,244,852 字节，减少约 1.12 GB；清单与回执同目录保存。

业务模块、运行资源、长期测试、依赖与活动运行目录保持原路径。原项目数据库、冻结包、attempt、远端文件和研究输入保持。旧文档中的 development-backups/日期目录对应 development-archives/日期目录.tar.gz；需要恢复时先查看 tar 清单，仅解压所需文件。应用备份宜保持压缩，避免再次被系统识别为多个入口。

## 验收及边界

真实研究记录的隔离副本验证移除预览、取消、确认、列表更新和恢复；真实双自旋与 SOC 绘图缓存核对相对/绝对带边及来源说明。未删除实际使用中的服务器，未提交、取消或重跑研究任务。正式 71 个 attempts、7 条链、1 个扫描的完整 JSON 内容保持；worker 仍启用且为 300 秒。

服务器移除、嵌套派发锁与历史解释器读取、已有绘图解析及原启动检查通过。活动源全量后端 678 项（3 跳过）、前端 139 项及类型/构建通过；增补重新登记边界后，公开副本后端 673 项（3 跳过）、前端 136 项及类型/构建通过。长期后端回归依赖既有本机登记表和原脚本夹具：未提供这些夹具时出现 3 失败/42 错误；使用与上一包相同的夹具后通过。夹具不发布，不能据此声称空配置安装环境全量回归通过。平台图标容器和 Mac 打包资源核验通过；Mac 应用索引已识别 ICNS。Windows 新安装器尚未实机安装，本轮仅验证资源、快捷方式及配置合同。

**本轮只更新源码和本机开发入口，不更新 Release 版本，不构建或发布安装包。** 既有 beta 安装包不会因源码更新自动获得新图标，下一次明确发布后再作 Windows 实机验证。
