# 同节点重算保留实际运行结构

## 修复行为

同节点“读取电荷重算”现在从所选历史 attempt 读取实际 POSCAR，与该次 CHGCAR / WAVECAR 绑定；不再用项目根结构重新生成 POSCAR。继续未完成优化仍使用所选历史 CONTCAR。高级手动来源的项目配置结构语义保留，并在界面与同节点重算区分。

冻结时核对实际 POSCAR 的内容哈希、元素及原子顺序，并与原 attempt 保存的输入身份比较。原任务从计算链上游物化结构时，以其来源文件计划中 POSCAR 的内容身份为准，不把 POSCAR.reference 当作实际输入。缺少、变化或无法核对的结构明确阻止冻结，不回退原始结构。

草稿仅展示 POSCAR.reference，避免把未物化的项目根结构当作实际输入。新冻结包保存所选 POSCAR 原文、实际几何身份、来源任务与体积；共享生成报告和项目草稿保持。派发前再次核对同一份来源文件，POSCAR 独立复制，避免硬链接改写历史输入。依赖上游 CONTCAR 的现有合同保留。

旧冻结包、授权、历史 attempt 和结果不自动迁移或改写。对已使用错误结构完成的历史重算，应明确选正确历史来源或上游、重新审阅新输入；修复不追溯改变已完成计算，也不自动提交或重投。
