# 多结果晶格对比 · 2026-10-09

## 使用

在“多个计算结果比较”选择普通任务或参数迭代 case，点击“读取并比较指标”。晶格表并排显示 a、b、c（Å）、α、β、γ（°）和晶胞体积（Å³），沿用实际 INCAR 差异表，包括 U/J、ENCUT、ISIF 和优化设置。

选择“变化量参考结果”可查看 Δa、Δb、Δc、ΔV 的百分比。参考切换和趋势下拉选择只使用已读数据，不再次访问服务器。趋势指标支持全部七项晶格指标；横轴保持已选结果顺序，序号对应上表。CSV 导出包含数值、参考、变化量、实际 INCAR 参数、数值状态及来源文件校验，可用于另行整理文献比较或按参数绘图。

## 来源与科学边界

晶格取同一 attempt 的 OUTCAR 最后一组 direct lattice vectors，由现有 pymatgen Lattice 求长度、夹角和体积。只回传有限摘要及源文件 SHA-256、晶格头行号，不复制原始大文件、不改变研究输入或派发状态。读取前后 hash 必须一致；变化或校验缺失要求重新读取。最后一组缺失、截断、非有限或退化时保留为空，显示具体原因，不回退项目原始结构或较早晶格。

展示的是实际计算晶胞，不自动转换原胞、常规胞、超胞或 a/b/c 轴序。文献比较须核对晶胞表示、组成、赝势及优化条件；非优化阶段不标为新的平衡晶格。程序结束、电子收敛、离子收敛和物理验证分别看待。

晶格趋势允许不同 U/J 等参数，连接仍要求相邻、同阶段、同晶胞化学组成与赝势、有效来源、程序结束和电子收敛；relax 还要求离子收敛。缺失值不补零，未确认收敛的数值用棕色显示。原能量趋势继续要求同模型，不将不同 U/J 的能量线改为可比。
