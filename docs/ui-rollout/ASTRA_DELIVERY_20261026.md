- 删除使用原分析的类型与 ID，覆盖 v2 扩展、v1/本地分析、绘图和比较记录；已登记数据集仍使用独立的数据集 ID。登记快照与原历史记录分别回收。
- 删除后刷新本机列表并清除被删除项的选择；从统一回收站恢复原历史后自动刷新列表。原有确认边界、远端文件和独立登记快照保留。
