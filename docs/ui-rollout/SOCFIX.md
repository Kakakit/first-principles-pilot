# SOC 运行证据非有限数值与 HTTP 500 修复

修复电子迭代证据中的非有限数值导致任务列表、详情与项目摘要 HTTP 500；现有本机服务已正常重启，真实项目六类只读接口均返回 200，原作业号与调度状态继续保留。

## 原因与修改

运行中 SOC 任务的 `evidence.last_delta_eps` 为 `-Infinity`。旧解析器直接使用 `float()`，Python 允许该值进入本机 JSON 记录，而 Starlette 返回标准 JSON 时拒绝 Infinity/NaN，抛出 `Out of range float values are not JSON compliant`。一条异常证据由此使包含该任务的列表与摘要一起失败；不能根据页面报错判断提交未成功。

- 共用 `execution_evidence.electronic()` 解析当前电子迭代：仅接受有限数值和正 EDIFF，两个差值同时满足阈值才确认数值收敛。溢出、Infinity、NaN、星号及不可解析值显示为空，提供 `numeric_error`。
- `get()`、`history()` 和保存时读取旧版本证据采用同一兼容逻辑；旧非有限值投影为空并取消其收敛断言。单纯查看不改写数据库，不迁移或新建 attempt。
- 原始文本回执、调度状态、作业号、路径与输入保持原来的处理方式；没有重投、取消任务或强制更新远端证据。

- 独立交付副本共 58 项相关检查通过：新回归、执行状态、来源合同及冻结备注；活动源另跑 7 项新回归通过。没有安装依赖或建立环境。
- 使用真实本机数据库的临时副本，六类接口在旧读取逻辑下均复现相同序列化异常，修复后均可生成标准 JSON；核对目标数据库 body 完全一致。测试不启动 worker，禁止 SSH。
- 通过现有控制中心重启本机工作台；派发中保护正常生效，重启前没有 DISPATCHING 记录。随后对正式 API 的完整/摘要任务列表、任务详情、项目摘要和完整/摘要节点记录各做一次只读 HTTP 请求，六项均返回 200。
- 重启后的原任务本机回执仍为 RUNNING；本轮没有新建提交或主动核查远端。这里不声称 VASP 正常结束、已收敛或已通过物理审核。非有限电子迭代本身仍属于需要检查的计算证据。
