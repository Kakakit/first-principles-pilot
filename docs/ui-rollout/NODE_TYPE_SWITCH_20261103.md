# 复制节点类型切换修复 · 2026-11-03

复制节点没有任务记录却无法切换，是类型控件仍依赖“已保存”状态。自动保存现为停止编辑30秒后执行，造成新节点在等待保存期间被锁住。

`NodeTypeSwitch` 改用已有 POST 草稿核查接口，将当前项目发送到本机后端核对节点历史，打开控件与确认切换均使用同一接口。新建或复制的普通 VASP 节点无需先保存即可切换；历史保护沿用原规则，并直接显示禁止原因。主页面移除旧保存状态参数。未修改后端核查或实际保存保护。
