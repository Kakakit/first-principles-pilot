# 导航、任务结构提取与卡片继承文件 · 2026-10-30

## 操作

顶部主导航连续排列为「项目与流程 → 计算配置 → 运行与监控 → 结果与后处理」。「结构管理」放在项目标题所在的上方工具区。单击卡片继续选中；双击计算卡片打开该节点配置，双击结构卡片打开对应结构。右栏配置按钮固定放在节点名称下面；切换结构时同步画布选择。

在结果页的 POSCAR／CONTCAR 文件行或完整预览中点击 **添加为结构节点**，自动回到画布并选中新节点。新名称为「CONTCAR 结构」或「POSCAR 结构」，重名时加序号，可继续改名。原节点到副本使用标有文件名的虚线；副本到后续计算继续使用普通输入实线。按用户最后的反馈，卡片只显示 **继承：CONTCAR、CHGCAR、WAVECAR** 这样的简短列表，实际未选用的文件不显示；来源线上也不显示作业号。精确运行版本、文件路径、冻结备注和作业标识保留在折叠详情及原任务中。

提取只复制结构，不自动携带电子文件或旧作业参数。可以编辑晶胞、原子和 POSCAR，然后将该结构连接到新的 relax／SCF 节点作为输入。原文件与 attempt 保留，原字节和哈希随副本保存。替换为另一份导入文件时清除旧来源关联；编辑同一份结构仍保留原来源。重复提取同一 attempt、同一路径和同一文件版本时定位已有未编辑节点；已有副本被编辑后，可再提取新的原始副本。

文件可读、完整、可解析即可提取，不以数值收敛作为禁止条件。运行中或 UNKNOWN 也可显式提取当前副本，说明文件后续变化不会同步；既有任务状态保留。沿用 256 KiB／1500 原子的结构导入边界，拒绝部分预览、路径越界和读取期间长度不一致的内容。

## 实现边界

- 来源事实保存在结构节点的可选 `structureOrigin`，包含项目、节点、attempt、文件及哈希；可选 `structureOriginNodeId` 仅用于画布定位。来源虚线由这些元数据派生，不进入 `Project.edges`，不参与执行依赖、参数继承、循环判断或派发。
- 导入或恢复为新项目时仅重映射画布引用，保留原运行身份；删除来源节点后仍保留文字记录。没有历史 attempt、目录、授权或科研文件迁移。
- 继承文件展示调用现有 `source_contracts.plan`，旧扫描使用其实际基础计算与覆盖配置；不在前端重写另一套来源规则。拖动、缩放、改名称不改变来源查询指纹；查询只在本机计算，无 SSH 和文件核验。
- 结构提取复用已有小文件完整预览与终态缓存；并发提取合并读取，同源文件缓存命中不再次连接远端。未命中时只在用户点击后使用现有有界读取，不递归扫描或自动刷新。
- 共用宿主 React／React Flow、原结构解析器、已有缓存与工作区保存机制，无新依赖或工作流框架。
