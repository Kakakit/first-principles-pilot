# D 包：从零上手与 Windows 测试交付

日期：2026-10-04。目标：Windows 10/11 x64，已有 CPython 3.11，可联网安装依赖，不需要 Node。Windows 原生验收待用户测试机完成；这份记录区分 Mac 实测、模拟检查与待验证项目。

## 本轮交付

- Python 启动器以一个本机端口提供预构建页面与 API；依赖、端口、可写目录错误提供可修正提示。已有解释器来自机器配置或环境变量，不创建环境。
- 首次设置保存数据目录、合法 POTCAR 库、研究目录、端口与监控开关；更换目录或端口需重启，原目录保留。
- 新服务器只读取本机已有 SSH 别名，登记 PBS/Slurm、程序/MPI/环境、远端 Python、队列与工作区；不复制密钥或改写 SSH config，不继承历史成功证据。
- Windows 文件锁、非破坏性 PID 存活检查、持久 SSH 管道读取、本机 TCP 回传桥、远端 POSIX 路径及脚本 LF 执行副本。保留原稿和原 hash；单文件 10 MiB 回传规则继续执行。
- 启动器退出时停止自己创建的监控进程；异常退出后监控进程检测启动器消失并退出。不会终止其他工作台进程。
- 发布白名单排除个人配置、数据库、POTCAR、研究数据、开发临时脚本和 node_modules；随包提供结构示例、扩展模板、原协议、第三方许可证和逐文件清单。
