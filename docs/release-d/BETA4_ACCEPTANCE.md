## 软件回归

前端 160 项全部通过；TypeScript 与生产构建通过。构建保留既有 3Dmol eval 和大块体积提示。README、贡献指南和安装文档的本地链接与代码围栏检查通过。

发行版 Python 对当前源码与准确 main 基线分别执行完整后端回归，两者均为 865 项、4 个失败、41 个错误、13 项跳过，失败 / 错误身份集合完全相同，新增失败 0。既有环境问题主要涉及未分发的主机登记、脚本及研究夹具；它们仍记作失败，不声称干净环境全量通过。回执状态为 `NO_NEW_FAILURES`，`whole_suite_green=false`。

首次使用开发解释器、受限沙箱执行的诊断额外遇到本机端口权限问题；以上发布对照已改为包内运行时和正常回环端口权限。测试专用夹具或私人配置没有加入发行物。

## 范围

Windows 和 Intel Mac 本次不构建、不发布。其他设备、真实 SSH、外部扩展环境和科研流程需对应验收；软件打包与回归不证明数值收敛或物理模型有效性。

完整回归与原生启动回执随 Release 分发；本机仅保留发行物、最小源码差异与短验收记录，不长期保留展开应用和完整测试副本。
