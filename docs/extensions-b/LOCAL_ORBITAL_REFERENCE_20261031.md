# 2.3.0：VASP 占据 → Wannier 能级的局域参考衔接

## 两步使用

1. 从已完成、无SOC的静态VASP任务新建“轨道占据”后处理，分别填写 `CrO6`、`FeO4`。在结果页点击“导出至 Wannier 的局域参考”；通用产物区也提供 `local-orbital-reference.json`。
2. 从对应的Wannier结果新建能级分析，在“VASP → Wannier 参考衔接”选择这个JSON。多面体类型留空即可继承；上下自旋来源可以共用同一参考。检查适用性后正常执行，默认查看继承的局域配位架。

参考文件包含冻结晶胞、原子顺序/分数坐标、中心及配体周期镜像、实际键向量、局域轴、PAW占据摘要及来源。参考不依赖数据库或本机路径，不自行读取其它文件；通过现有参数JSON冻结，远端执行同样可读。文件上限2 MiB；多来源结构相同导致歧义时，在结果页选择单一来源导出。结构匹配容差0.0001 Å，允许同一原子的整晶格周期换位，不自动重排原子或替换历史结构。

结构、元素、原子顺序、配体几何、局域轴或显式类型冲突会在检查时说明原因。参考导入后沿用其局域轴，不再重新拟合导致等价轴随机互换。当前最大键长仍适用；参考中超过默认3 Å的壳层需要核对高级设置。移除参考即可恢复原有独立Wannier分析。旧VASP记录缺少冻结结构/参考时，从同一冻结任务新建后处理，不重跑VASP或Wannier，也不向历史补用最新草稿。

## 科学边界

只传递几何坐标架、原子对应及占据参考，不把占据矩阵本征矢当作最终Wannier轨道，不按轨道数猜标签，不以占据匹配自动修正hr或对齐Wannier gauge。初始投影、中心仅提供对应候选；最终WF身份仍需波函数/重叠及能带拟合证据。现阶段不会自动执行该额外物理审核。来源声明保留，结构一致不证明同一电子设置、磁态或DFT父任务。PAW与Wannier投影空间不同，不要求占据数完全相等，不自动做跨方法减法。

同一完整d壳内执行完整复矩阵的基底变换：先按.win投影轴转到全局候选，再按继承局域轴计算 `H_local = R_local @ H_global @ R_local.T`。单壳本征值和迹保持；改变的是轨道组成和局域分组解释。输出继续标注有效onsite而非纯静电晶场。SOC仅继承空间配位架，不继承自然占据自旋态或去除SOC；10维spinor块保留，不能据此输出无SOC的e/t劈裂。
