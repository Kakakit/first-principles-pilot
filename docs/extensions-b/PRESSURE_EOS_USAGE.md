# 压力结构与 EOS 初版

包：`resources/extensions/pressure-structure-eos`，版本 1.0.1。使用和物理边界详见包内 README。

入口：项目 → 结果与后处理 → 打开一个已完成任务 → 运行后处理 → 压力结构与 EOS 分析 → 批量选择已有任务 → 刷新/检查/运行。支持 1–64 来源；少于 6 点仍可自由绘图和看证据，但不做 EOS。

默认 a/b/c–V 三曲线；可点图例隐藏，或换 E–V 看能量与拟合。所有晶格参数都属于实际计算晶胞。原胞不能直接标作文献常规晶胞常数。

页面修改组名或取消拟合点后，使用“应用分组并重新拟合”。仅冻结结果 JSON 参与重算，保存为新展示版本，原分析文件和研究输入保留。归一化在能量/体积两边同步，压力和晶格长度不随原子数缩放。

通用展示请求追加可选 `view_state`（已保存状态快照）；页面 RPC `refresh-view` 只允许原分析的可更新展示，调用既有展示生成流程。历史/归档展示不能发起更新，原 read-file/read-state/save-state/download 行为保留。宿主没有 EOS 特例。

不提交计算、不自动同步 GitHub。首次真实验收使用 Ce 相变研究的 0.9–1.1 扫描，冻结样例和回执保存在本机开发备份目录；验收结论见 CHECKPOINT。

## 多选与批量命名

纵轴 Y 下拉菜单内可逐项多选，已选项显示 ✓，点击“应用 Y 轴选择”绘图。不同单位的量置灰并注明不兼容；全部来源未提供的量也置灰。切换物理量类别时先“清空选择”，再选新量；“取消”保留当前图。图例纵向排列，逐条点击可隐藏。

在数据表“批量选择”列勾选多个点，输入“批量组名”，点击“应用批量组名”。“全选数据点”可一次选中全部点，批量选择与拟合勾选互不影响。改组后再点击“应用分组并重新拟合”，不兼容设置的拟合门禁仍保留；仅改坐标可直接保存展示设置。
