# TB2J 2.2.0：距离筛选、近邻总览与自动标签

## 原因与行为

本机所存最近一次完成分析未记录 rcut，实际命令也没有 --rcut。4494 条完整原生记录中有 676 条 d < 9 Å，并非没有短程交换；基础结果按 R 排列且只展示前 1000 项，开头先列远距离。独立展示生成又被传给 execution.ssh 的不兼容 lane 参数阻断，因此筛选/排序入口未能出现。数组编辑按钮依赖未加载的图标字体，显示为空框。

现版常用区为磁性元素、默认 9 Å 最大距离、固定三方向网格和轨道分解；其余参数折叠。参数说明并排显示，条件项按模式出现，数组使用中文文字按钮。冻结预览、请求和官方 CLI --rcut 一致；实际返回越界记录会明确失败并保留原产物。

默认结果为统一坐标的元素对分面＋几何近邻分组，可切换叠加；支持带符号 J 和 |J|、距离排序、两端原子和 Rx/Ry/Rz 筛选。严格 d < 上界，R 为整数晶格平移。分组跨度容差默认 0.001 Å，保留原始方向和记录数，统计范围与中位数不作为晶体学等价或物理模型约化。

点击交换项显示 i 行/j 列的轨道矩阵、以零为中点的带符号配色、贡献强度明细、矩阵和与原始总 J 差值。筛选、排序覆盖全部数据，再分页；显示圆整不影响下载精度。

## 自动标签的证据边界

本次冻结投影为明确的 Cr:d / Fe:d / O:p。按 assigned_basis 的全局 WF 序号交叉核对投影、原子顺序、矩阵维度和周期性中心归属，30 个磁性轨道自动获得初始投影参考名称。上下自旋不一致、随机/杂化/不能解释的投影、基底序号缺失、SOC 顺序或中心归属不明时保留原始序号并解释原因。自动名称不证明最终 WF 纯度，不自动赋予局域 t₂g/e_g。

手动覆盖仍可选，独立保存，不回写原始 command/result/exchange 或科学验证状态。源文件和已完成研究计算保持。

## 通用接入

presentation 可选 location=local 和 inputs 白名单；缺省保持 source 和旧解释器行为。本地展示只复制已回传且每文件不超过 10 MiB 的必要输入，缺失不发 SSH。TB2J 使用完整 CSV 和 stdlib 整理，无需本机导入 TB2J。展示实际位置/Python 单独记录，原分析的服务器/Python 继续冻结。所有元素/轨道/统计/绘图逻辑位于扩展；宿主没有 TB2J ID 或科学格式分派。

旧扩展、旧请求和已生成历史展示保留；卸载不影响保存的展示，整理失败不改变分析终态。

宿主通用适配与扩展功能分开提交。通用字段均为可选，不安装 TB2J 时保持原扩展行为；后续只修改扩展时只验证扩展及相关接口，不重复全量回归。

## 验收

- 本机真实完整 CSV 的 4494 条交换记录、112350 条轨道矩阵逐项对照展示分片；d < 9 Å 得到 676 条，其中 Cr↔Cr 304、Cr↔Fe 304、Fe↔Fe 68；全部值、方向、R、单位和索引保持。
- 验证最大距离边界、负 J 与绝对值排序、几何分组、矩阵完整性、双通道/缺失/随机/SOC 标签和原文件保护。独立扩展测试通过。
- 隔离 API 使用真实历史副本、禁止 SSH 和研究执行。浏览器验证常用/高级说明、文字按钮、9 Å 命令预览、4494 条完整排序与45页、同晶胞30条、第一 Cr↔Fe 近邻16条和轨道热图/导出。Safari 和内嵌浏览器分别检查布局与可交互状态。
- 最终测试数量、构建和离线一致性回执见本轮 CHECKPOINT。未把测试或绘图一致性当成数值收敛；数值/物理仍未验证，SOC 单方向状态保持。

本轮不连接故障服务器、不重跑研究计算、不恢复队列、不发布安装包。正式服务与 worker 启停配置保持；正常重启后加载新宿主。一次性脚本、私有副本和截图归档在本机 development-backups/tb2j-usability-20261020，不上传 GitHub。同步仅包含本轮源码增量、模板与说明，不覆盖其他开发工作。
