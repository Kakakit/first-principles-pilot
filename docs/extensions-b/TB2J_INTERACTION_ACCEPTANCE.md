# TB2J 参数交互与服务器 Python 验收 · 2026-10-06

TB2J 2.0.1 修复了“填写必要选项”无法交互的问题，并明确服务器 Python 的选择入口。主程序提供通用来源、表单和运行时服务；扩展仍是独立 CLI，负责输入检查、选项到 argv 的转换、调用官方 TB2J 和结果整理。

## 使用流程

1. 打开完成的 Wannier 来源，选择 TB2J，默认在来源服务器直接命令行运行。
2. 点击“登记服务器 Python”。选择已有 SSH 主机，填写该服务器已有环境中 Python 的绝对路径和分析工作区，保存后按服务器复用。调度资源配置保持折叠，TB2J 不使用这些字段。
3. 参数可以先填写。未登记运行时或缺少输入只阻止检查、预览和运行；不会锁住文本、数值、选择或勾选框。
4. 元素选项来自冻结 `.win` 的结构元素，用户决定哪些是磁性元素，不自动推断。旧来源缺少元素摘要时保留手工填写。
5. 审阅脚本后执行一次。所选 Python 实际导入依赖、检查 TB2J 版本和 CLI 参数，再检查来源内容并运行。登记路径本身不代表环境可用；不安装或升级环境，不依赖 shell activate，也不切换到 PATH 中其他命令。

来源和父来源显示可识别的运行名称或 job ID；内部记录标识保留在下载的执行记录中。预览使用合法的 `analysis-preview` 目录占位符，真实运行使用独立目录，修复了预览占位符被安全路径校验拒绝的问题。
