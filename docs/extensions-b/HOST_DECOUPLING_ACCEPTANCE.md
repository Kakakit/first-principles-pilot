- 扩展管理只展示已安装包。下载 extensions 分支 ZIP 后导入，或导入其独立源码目录；更新扩展只需重新导入该包。
- 已安装目录、启停配置、环境配置、冻结运行副本和历史结果均继续读取原位。本轮不升级或重新安装用户扩展，不迁移研究目录。
