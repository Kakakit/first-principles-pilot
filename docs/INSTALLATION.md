# 浏览器工作台安装测试版

安装后点击 First Principles Pilot 图标，浏览器自动打开工作台。包内自带 Python 和锁定依赖，无需安装 Node、Python 或运行 npm。界面和计算逻辑共用一份代码，安装包按系统/架构分别构建。

## 下载与安装

从本仓库 GitHub Releases 下载对应安装包。仓库为私有，须先登录获授权的 GitHub 账号。不要下载页面自动生成的 Source code ZIP 作为运行包。

- **Windows 10/11 x64**：下载 `FPilot-1.1.0-beta.1-Windows-x64-Setup.exe`，双击安装。默认安装到当前用户的应用目录，无需管理员权限。开始菜单有启动、停止和导出诊断三个入口，可创建桌面快捷方式。
- **Apple Silicon Mac**：下载名称含 `macos-arm64` 的 DMG，打开并把应用拖入 Applications。
- **Intel Mac**：选择名称含 `macos-x64` 的 DMG，按同样方式安装。

这是未使用商业代码签名证书的测试版。Windows SmartScreen/macOS Gatekeeper 可能提示发布者未验证；核对这是自己授权仓库的发布和 SHA256 后决定是否允许运行。Mac 的临时签名不等于 Developer ID 签名或公证。本轮不把打包成功当成用户机器安装验收。

## 启动、停止和重启

点击应用图标，启动本机后台和浏览器；重复打开复用已有实例。网页顶部“工作台控制”可打开控制页，提供启动、停止、重启、退出和日志。关闭浏览器继续保留后台监控。

停止和更新前保存草稿。提交/上传回执尚未完成时拒绝停止/重启；正常停止等待当前操作完成，不强杀远端提交命令。远端排队和运行作业保持，本机监控和后续派发暂停。

Windows 的“停止工作台”入口同时退出控制中心。Mac 在控制页点击“退出控制中心”。更新或卸载前须完成退出，避免正在使用的运行环境被替换；安装器不会自动杀进程。端口冲突显示在控制页日志，不会占用或关闭其他程序。

## 数据与首次配置

- Windows 配置、日志和项目默认存于 `%LOCALAPPDATA%\FirstPrinciplesPilot`。
- Mac 存于 `~/Library/Application Support/FirstPrinciplesPilot`。
- 安装目录只保存程序，更新和卸载不删除用户数据。卸载后重新安装可继续读取原工作区。
- 旧开发工作区和旧 ZIP 的数据保留原位，不自动导入。跨设备接续使用“下载并接管”，复制草稿使用原 JSON 导入入口。
- 可在设置更改项目数据目录，原目录不自动移动。修改后在控制页重启。

第一次打开确认路径，再登记自己的 SSH 服务器、合法 POTCAR 库和任务脚本。安装包不包含研究数据、密钥、SSH config、私人脚本或赝势。Windows 仍需系统 OpenSSH Client；在设置中检查 SSH 是否可用并配置免交互认证。外部扩展有额外依赖时在扩展环境设置中指定自己的研究环境，启动环境保持独立。

## Windows 测试顺序

1. 安装器正常结束，从桌面或开始菜单启动，浏览器出现工作台。
2. 重复点击启动，只有一个工作台实例和一个监控 worker。
3. 导入自己的 POSCAR，查看结构，切换各板块；保存一个草稿，刷新后仍可见。
4. “工作台控制”检查日志、停止和重启，草稿保持。
5. 设置 SSH 后先做只读连接与节点检测；研究提交仍通过原输入审查与授权入口。
6. 停止后覆盖安装同版本，原草稿保持；卸载保留数据。

失败时使用开始菜单“导出启动诊断”，结果写入用户数据目录 `release-diagnostics.json`；另提供 `controller/workbench.log` 中相关启动错误。诊断不连接服务器，不导出密钥、POTCAR 或项目内容。

## 发布与更新

首版通过 GitHub Release 下载新安装包并覆盖更新。源码变化不会自动修改已经下载的包。发布流水线锁定 Python 下载身份，安装二进制依赖并检查冲突，运行回归，再在 Windows 和 Mac 启动真实打包后的工作台与 worker；原生启动失败不发布安装器。完整科学计算、SSH 认证、图形与用户系统设置仍需实际机器验收。
