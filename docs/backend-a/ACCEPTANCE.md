## 已完成的行为

- 计算链的勾选只决定本次执行范围。取消勾选上游后保留连线，预览为其查找历史结果；直接历史来源成为依赖边界，不再要求选其祖先。复用来源限定为同项目、同节点、同主机的受控 attempt；最终电子收敛由最后一步数值判断，relax 还需要离子收敛。缺文件、不同主机、UNKNOWN、未收敛分别列出原因。
- 唯一合格且有效物理输入一致自动选择。多来源或当前草稿不同须显式选择。比较采用历史冻结 INCAR、POTCAR、KPOINTS 与结构输入；运行时并行设置、输出开关、续算读文件开关不视作物理模型差异。下游模型差异使用所选历史 INCAR，而非当前上游草稿。
- 冻结到精确 attempt、来源路径、输入包、收敛证据、文件回执与策略。worker 不选“最新结果”；来源元数据变化使派发阻断。复用节点不生成新 attempt、不占作业/续算/资源额度。派发仍使用现有准备、输入审查、额度事务、确定性 ID 与单次提交路径。
- 输入预览共享节点/邻接/结构生成上下文；POTCAR 解析、结构路径和已验证冻结包使用有界缓存。文件缓存包含实际路径、设备/inode、大小、纳秒修改时间与 ctime，变化后重读检查；调用者拿到独立结果，避免污染缓存。冻结复用本请求生成的报告。
- 整链脚本通过一个批量请求预览，相同资源/运行时只渲染一次。标准/SOC 程序可在一次主机诊断中同时检查，冻结授权按运行时组合复用该报告。同一 worker 周期共享主机容量与队列查询；每次真正提交始终重新查询，繁忙等待、离线/来源/输入错误分别处理。
- 完整运行时检查按配置缓存，配置变化、执行失败、诊断异常或显式完整诊断使缓存失效。实时容量与队列不长期缓存。没有状态变化时不写计算链记录、不增加 revision；冲突检查继续有效。
- 新 VASP 输入冻结默认 `lightweight`。CONTCAR 与小型物理输入继续 SHA；CHGCAR/WAVECAR 和 Wannier `.amn/.mmn/.eig/.chk` 默认非空普通文件、大小及高精度修改时间。复制/链接前后检查来源，核对目标大小；可写文件保持独立复制或写时复制。旧冻结/准备记录没有策略字段时沿用原完整内容策略。
- Wannier 接口与独立补画准备/提交/复制接入同一轻量规则，`.win` 保留内容身份与小文件安全回传。主动完整核验在结果页的执行证据中提供；它建立 SHA 回执并比较已有身份，不改写准备合同。只有历史已记录 SHA 的文件才能声明内容比较成立。
- 后处理目录与适用列表使用同一个文件清单；切换子页复用结果，运行中列表按既有 30 秒缓存规则刷新；显式文件刷新使适用结果失效。

## 接口与使用

`POST /api/chains/preview` 和 `/freeze` 接受 `source_alias`、`reuse_sources`（来源节点 → attempt）及 `verification_mode`（`lightweight`/`full`）。预览返回 `sources` 候选/原因、已解析的 `reuse_sources`/`reuse_bindings`；定义身份包含绑定与策略，冻结时必须匹配预览。冻结记录保存精确绑定。

`POST /api/chains/{id}/resources-preview` 接受项目、配置和逐节点候选池，返回批量脚本；正式授权仍比较用户审阅的准确脚本和资源。

`POST /api/execution/{id}/verify-source-files` 是主动完整核验；返回文件 SHA、变化列表和本次检查时间。旧 SHA 保留，新轻量 receipt 不伪装为完整内容证据。要改变准备合同，应重新预览/冻结/准备。

`POST /api/server/probe` 和 `/api/wannier90/probe` 支持 `force: true` 完整重查。计算链中的“重新诊断”触发完整检查；自动预览、授权与 worker 使用缓存运行时加实时容量。路径内的程序被人工更新而配置没变时，应主动完整重查。
