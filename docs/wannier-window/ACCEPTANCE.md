## 核心复核结论

按活动 AGENTS 的单 agent 约束完成定向自审，未使用代理：①窗口只修改四个能量 tag，EF 与矩阵身份不漂移；②case 包从原完整矩阵开始，不上传旧 checkpoint；③共用 worker、全局额度和分支绑定，提交入口还检查 ACTIVE/准确 case/并行上限；④PREPARED 与 UNKNOWN 恢复路径不会创建新身份重复派发；⑤回收和清理不选择替代来源；⑥扫描 attempt 的执行归属为扫描节点，不覆盖基础 Wannier 卡片状态。

真实 PBS/Slurm/Wannier 运行、文件系统硬链接能力、实际程序数值收敛、材料子空间对应关系和拟合质量尚未建立；本轮只使用模拟回执。真实验证需用户逐轮核对后提交，并记录精确 job ID、完整 `.wout` 和同源参考。

浏览器没有在真实 DFT 数据上生成指标叠图；独立协议/固定取样/对应合同及已有绘图路径通过自动测试，实际材料需要人工确认连续能带对应有效。projectability/特殊 k 区域、多于 num_wann 的投影来源明确不支持该模式。没有兼容参考仍可运行与人工评估。
