# C1：计算配置与运行闭环

本包属于 2026-10-01 产品优化计划中的页面闭环，不等同于历史 Wannier 接口开发包的 C1 命名。下一开发包为独立扩展协议 B。

## 操作流程

结构导入 → 计算流程中连接节点 → 计算配置（物理参数；k 点/赝势/文件审查）→ 确认并冻结 → 用此版本准备运行 → 当前节点或计算链审阅 → 核对资源/来源/脚本 → 单独确认提交 → 结果与后处理。

参数、来源与冻结合同仍由原后端决定。界面不自动补物理参数、不自动提交、不把轻量核验当内容一致，也不把程序结束当科学结论。

## 信息与状态

- App 中的当前节点同时作用于配置与单节点运行；两个 VASP 子面板隐藏独立节点选择，避免编辑两个不同节点。
- `CalculationWorkspace` 使配置与运行审阅共用一个按项目/节点定位的组件。VASP 参数/输入在运行审阅时保留挂载；Wannier 和扫描各有配置/运行视图，切换不创建新组件。
- 冻结按钮下方显示明确版本及“用此版本准备运行”。`inputForReview` 只接受该节点的可审阅版本；指定版本缺失/已回收/属其他节点时不替换。普通进入时只有唯一合格版本自动选择。
- 草稿变化复用 InputPanel 原有 epoch 保护，清除报告、冻结按钮状态及新加的审阅确认。历史 ZIP 不改写。
- 当前节点执行与整链执行是显式范围选择；整链界面展示的画布定位不改变下方勾选范围。原链复用规则完整保留。
- 链授权确认框移到节点来源差异、服务器资源和候选脚本之后，与授权按钮相邻。

## 布局

- 项目名称与保存状态共用紧凑项目头；项目备份、配方、回收操作按需展开。
- 路径编辑按需展开，保留产生 attempt 后锁定身份的原规则。
- 画布工具只出现于流程页；底部任务栏默认折叠。
- 正文基础 15 px，关键辅助说明 13 px；确认框横向排列，版本默认短显。
- 结果入口明确为“结果与后处理”，沿用现有结果/绘图/比较实现；本包不迁移扩展执行或增加科学算法。
