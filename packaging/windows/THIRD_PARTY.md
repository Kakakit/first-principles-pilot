# Windows 安装器语言文件

`ChineseSimplified.isl` 来自 Inno Setup 官方源码仓库 `Files/Languages/ChineseSimplified.isl`，文件声明适用于 Inno Setup 6.5.0+，保留原维护者和翻译说明。构建机的 Inno Setup 6.7.1 安装不自带该语言文件，因此随安装器源码保存一份。

来源：https://github.com/jrsoftware/issrc/blob/main/Files/Languages/ChineseSimplified.isl

此文件仅供 Inno Setup 编译中文安装向导；软件界面和用户配置不由它修改。Inno Setup 及其语言文件遵循上游许可，不包含研究资料。
