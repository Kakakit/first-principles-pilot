# Windows 测试版：首次使用

目标是 Windows 10/11 x64，已有 Python 3.11 x64，可联网安装依赖。页面已经构建，不需要安装 Node.js。这是跨平台测试包，尚未在真实 Windows 机器完成验收。

## 1. 解压与启动

1. 完整解压 ZIP，例如 `D:\FPilot`。也可放在含中文、空格的可写目录，不要直接在压缩包内启动。
2. 确认已有 Python 3.11 x64。双击 `install-dependencies.cmd`，向已有解释器安装锁定依赖；不会创建环境。首次下载通常需要数分钟。
3. 双击 `check.cmd`。依赖齐全时 `ready` 为 `true`，端口空闲时 `port_available` 为 `true`；结果保存在 `startup-check.json`。
4. 双击 `start.cmd`。浏览器自动打开 `http://127.0.0.1:8765`。保持启动窗口运行；关闭工作台时在该窗口按 Ctrl+C。

如果有多个 Python，可在同一个命令提示符中先执行：

```bat
set "FPILOT_PYTHON=C:\你的已有环境\python.exe"
install-dependencies.cmd
start.cmd
```

默认先选择 `py -3.11`，然后检查 PATH 中的 `python`。`FPILOT_PYTHON` 必须指向实际存在的解释器，不要填写文件夹。

## 2. 本机路径

点击欢迎栏“开始设置”或右上角“设置”，在“概览与外观”确认：

- **数据目录**：默认是解压目录下的 `workspace-data`，保存草稿、历史、冻结版本和缓存。
- **POTCAR 库**：选择自己的合法赝势库，各元素目录包含名为 `POTCAR` 的文件。包内不提供赝势、真实计算输入或科研数据。
- **研究目录**：可选，指向本机需要浏览的已有文件目录；留空也能导入结构文件。
- **网页端口**：默认 8765，冲突时改为其他端口。也可先用 `python launch.py --port 8766` 临时启动，再保存设置。
- **自动推进**：开启时监控现有任务并推进已经明确授权的计算链/扫描；新任务仍须审查、冻结和确认提交。

修改数据目录、研究目录、端口或自动推进开关后停止并重新启动。原数据保留，不自动移动。设置保存于解压目录的 `fpilot.local.json`；不要复制 Mac 上的路径配置过来。

## 3. SSH 和服务器

Windows OpenSSH Client 需能在终端运行 `ssh`。安装方式见 [Microsoft 官方说明](https://learn.microsoft.com/en-us/windows-server/administration/openssh/openssh_install_firstuse)。只需要客户端，服务器仍为 Linux PBS/Slurm。

在 `%USERPROFILE%\.ssh\config` 填写自己的明确别名，例如：

```text
Host my-lab
    HostName 你的服务器地址
    User 你的账号
    Port 22
    IdentityFile C:/Users/你的用户名/.ssh/你的已有密钥
```

SSH config 保存为 UTF-8 无 BOM。用终端运行 `ssh my-lab exit`，核对服务器指纹，完成认证。工作台使用 BatchMode，不能弹窗填写密码；请使用已配置好的密钥与 ssh-agent。密钥、账号和 SSH config 不由工作台改写或复制。

进入“设置 → 服务器与运行 → 登记自己的服务器”，填写调度器、队列、服务器已有 Python、程序/MPI/环境脚本路径。服务器路径是 Linux 的 `/...`，不能填写 `C:\...`。远端工作区采用现有规则 `$HOME/230269265lht` 或其子目录。

登记后导入自己的 PBS/Slurm 脚本，按程序保存默认配置，再运行只读诊断。导入原稿保留完整字节与来源，实际提交副本自动转换为 Linux LF 换行并去除开头 BOM。新登记服务器只记录用户配置，不继承开发者服务器的 smoke 成功证据。模板或执行环境缺失会明确提示；不会自动安装服务器软件。

Wannier90 使用同一设置入口选择“Wannier90”，导入该程序脚本并保存默认配置。没有随包提供个人服务器脚本。

## 4. 第一个本地流程

1. 使用自己的结构，或导入 `examples/Si.POSCAR`。该示例只用于检查导入、显示与结构分析，不包含可直接提交的 POTCAR。
2. 在“计算流程”添加/连接节点；在“计算配置”选择科学参数、赝势、来源，审查并冻结。
3. 在“运行”选择冻结输入、检测节点、修改基础资源配置、准备并核对最终脚本，最后明确提交一次。
4. 在“结果与后处理”查看准确 attempt、产物与分析。UNKNOWN 先核查原作业，不能重投。
5. 项目、输入和任务可移入本地回收站，恢复后自动计划保持暂停。清空回收站清理本地对象，不删除服务器任务或文件。

同一远端依赖分支沿用首次提交绑定的服务器，独立分支可以分别选服务器。大文件在服务器分析，受控回传只允许每个已知、普通、明确路径文件不超过 10 MiB。
